Excel 从入门到精通

一份系统化的 Excel 学习笔记，从界面操作、数据录入、函数公式、透视表图表，到高级数据分析与 VBA 自动化，配套公式模板、速记口诀与避坑指南，让你从「会点表格」进阶到「用表格解决问题」。

18 个章节 50+ 函数公式 入门 → 精通

01 认识 Excel 与工作界面

Excel 到底是什么

Excel 是微软出品的电子表格软件，本质是一个「二维表格 + 计算引擎 + 分析工具」的组合体。它能做的事远超「记台账」：

  • 记录：结构化存储数据（表格、工作簿、数据库式管理）
  • 计算：公式与函数自动计算（求和、查找、统计、判断）
  • 分析：排序筛选、透视表、图表、模拟分析
  • 展示：可视化图表、条件格式、仪表盘
  • 自动化：宏与 VBA、Power Query、Power Pivot
📌 一句话理解
Excel 像一本「会算账的本子」：手写表格只能记，Excel 的格子背后都能挂公式——格子只是壳，公式才是魂。

工作界面五大区域

区域 作用 高频入口
快速访问工具栏 常用命令快捷图标，可自定义 保存、撤销、重做
功能区（Ribbon） 按选项卡分组的所有命令（开始/插入/公式/数据…） 开始选项卡 90% 常用操作
编辑栏 显示/编辑选中单元格的内容或公式 点「fx」插入函数
工作表标签 切换/管理多个工作表 右键新建、重命名、着色
状态栏 显示求和/计数等统计、视图切换 右键可自定义显示项
🧠 速记口诀
「快工编表状，五区记心上；编辑栏看公式，状态栏出统计」——选中一列数字，状态栏右下角直接显示「求和 / 平均值 / 计数」，不用写公式也能快速瞄一眼。

02 单元格与基本操作

核心概念：单元格 / 行 / 列 / 区域

  • 单元格：行号 + 列标定位，如 A1（第 A 列第 1 行）
  • 区域：用冒号连接，如 A1:B10 表示 A1 到 B10 的矩形
  • 引用样式：默认 A1 样式；可选「文件 → 选项 → 公式 → R1C1 引用样式」
  • 名称框：编辑栏左侧显示当前单元格地址，也可输入名称跳转

选中技巧（键盘是效率核心）

操作 快捷键 说明
跳到数据边缘 Ctrl + 方向键 相当于「滚到连续数据的最后」
选中到数据边缘 Ctrl + Shift + 方向键 从当前格一直选中到边界
全选 Ctrl + A（连续数据区） 按一次选数据区，按两次选整表
选中整行/整列 Shift + 空格 / Ctrl + 空格 注意与输入法全角空格区分
跳转指定单元格 Ctrl + G（定位） 输入 A10000 直达，F5 同效

移动 / 复制 / 插入 / 删除

  • 拖拽移动：选中边缘出现四向箭头后拖动；Ctrl + 拖拽 = 复制
  • 剪贴板三键：Ctrl+X 剪切、Ctrl+C 复制、Ctrl+V 粘贴；粘贴后按 Ctrl 可展开「粘贴选项」
  • 插入行列：选中行/列 → 右键 → 插入；或 Ctrl+Shift+=
  • 删除行列：右键 → 删除；或 Ctrl+-
  • 隐藏行列：右键 → 隐藏；取消隐藏选中两侧再右键
⚠️ 避坑提示
① 合并单元格是万恶之源——筛选、排序、透视表都会出问题，尽量用「跨列居中」（设置单元格格式 → 对齐 → 水平对齐 → 跨列居中）代替合并；② 删除行列用右键删除，不要按 Delete（那只是清空内容，行列还在）。
🧠 速记口诀
「Ctrl+方向跳边界，Shift+方向扩选区；Ctrl+拖拽是复制，Delete 只清不留位」

03 数据录入与填充

数据类型：先分清「长相」和「本质」

类型 特点 典型例子
文本 默认左对齐，不参与计算 姓名、编号（身份证要设文本格式！）
数字 默认右对齐，参与计算 金额、数量
日期/时间 本质是数字（1900-01-01 = 1），右对齐 2026-09-01
逻辑 TRUE / FALSE 公式判断结果
错误值 #开头，说明公式有问题 #N/A、#DIV/0!
📌 一句话理解
显示 ≠ 存储。单元格「看起来是 2026/9/1」，本质是个数字 46266。日期格式乱了别慌，本质没变，改格式就能救回来。

自动填充：Excel 的魔法

  • 拖动填充柄：选中单元格右下角小方块，向下/右拖动即可填充
  • 双击填充柄：左边有连续数据时，双击自动填到底（效率神技）
  • 序列填充：填 1、2 再选中两格拖动 = 等差数列；按住 Ctrl 拖动 = 复制（1、1、1…）
  • 自定义序列：文件 → 选项 → 高级 → 编辑自定义列表，可让「周一、周二…」自动填充

批量录入三连

操作 快捷键 场景
批量填充选区 Ctrl + Enter 选中多个单元格输入内容后按此键，全部填入
向下填充 Ctrl + D 把上方单元格复制到下方选中区
向右填充 Ctrl + R 把左侧单元格复制到右侧选中区
向下补 0 / 补默认 选中空区按 Ctrl + Enter 输入 0 批量把空值补成 0
🧠 速记口诀
「双击右下角，填充自动跑；Ctrl+Enter 批量灌，Ctrl+D 往下抄」——录入效率的核心不是打字快，是少打字。

04 格式设置

数字格式：单元格格式是「外衣」

选中区域 → Ctrl+1 打开设置单元格格式（重要快捷键！），数字选项卡里切换：

格式 显示效果 适用
常规 输入什么显示什么 默认
数值 1234.57（可设小数位、千分位） 一般数字
货币 ¥1,234.57 金额
日期 2026/9/1 或 2026年9月1日 日期数据
百分比 12.5%（本质是 ×100 显示） 比例数据
自定义 按代码模板显示 高级需求

自定义格式代码（装逼利器）

代码 含义 示例
0 数字占位符，不足补 0 0000 → 12 显示为 0012
# 数字占位符，不补 0 #.## → 3.1 显示 3.1
0.00 强制两位小数 3 显示 3.00
#,##0 千分位分隔 1234567 显示 1,234,567
yyyy-mm-dd 日期格式模板 显示 2026-09-01
0%;-0% 正负分开显示（分号分段） 正数带%，负数带-和%
🧠 速记口诀
「0 补位、# 不补，Ctrl+1 全搞定；格式只改长相，不改本质」——自定义格式四段式：正数;负数;零;文本。

对齐、边框与格式刷

  • 自动换行：开始 → 自动换行；强制换行 Alt + Enter（单元格内）
  • 跨列居中：替代合并单元格的正确做法（对齐 → 水平对齐 → 跨列居中）
  • 格式刷：选中样板 → 点格式刷 → 刷目标；双击格式刷可连续刷多次，Esc 结束
  • 边框快捷键：Ctrl+Shift+7 细边框

05 工作表与工作簿管理

工作表基本操作

  • 新建：点标签栏 + 号；Shift+F11 也是新建工作表
  • 重命名：双击标签；标签颜色：右键 → 工作表标签颜色
  • 移动/复制：右键标签 → 移动或复制（勾选「建立副本」= 复制）
  • 隐藏：右键 → 隐藏；彻底隐藏需 VBA（Sheet.Visible = xlSheetVeryHidden）
  • 分组：Ctrl+点击 多选标签后可批量操作；右键 → 取消组合工作表

跨表 / 跨簿引用

=Sheet2!A1            同一工作簿内：工作表名 + 感叹号 + 单元格
=Sheet2!B2:B10        引用其他表的区域
='销售报表'!C5         表名带空格或特殊字符要加单引号
=[Book1.xlsx]Sheet1!A1 跨工作簿：文件名加方括号

冻结窗格：滚动时表头不消失

  1. 想冻结前 N 行：选中第 N+1 行的第一个单元格（如冻结第 1-2 行 → 选中 A3）
  2. 视图 → 冻结窗格 → 冻结首行 / 冻结首列 / 冻结拆分窗格
  3. 取消：视图 → 冻结窗格 → 取消冻结窗格
⚠️ 避坑提示
冻结的关键是「先选中冻结线右下方的单元格」——选中 A3 冻结的是 1-2 行；直接点「冻结首行」则只冻第一行。另外 Ctrl+Home 会跳到 A1，冻结窗格后它跳到「可滚动区域左上角」。
🧠 速记口诀
「跨表引用带表名，跨簿加方括号；冻结先选中线，Ctrl+Home 有讲究」

06 打印与视图

打印三板斧：区域 / 标题 / 缩放

  • 打印区域：选中区域 → 页面布局 → 打印区域 → 设置打印区域；只打这一块
  • 打印标题行：页面布局 → 打印标题 → 顶端标题行选择表头行（多页打印每页都带表头，必学）
  • 缩放一页：页面布局 → 缩放 → 宽度 1 页；或打印设置里「将工作表调整为一页」

分页预览：手动调分页

  1. 视图 → 分页预览（蓝色虚线是可调分页符）
  2. 拖动分页线调整每页内容；插入分页符：选中行 → 页面布局 → 分页符 → 插入分页符
  3. 结束：视图 → 普通

打印小技巧

需求 做法
每页都带表头 打印标题行设置（不是冻结窗格）
超宽表格打一页 缩放 → 宽度：1 页，高度：自动
不想打印某列 隐藏该列，或取消勾选打印区域中的列
打印行号列标 页面设置 → 工作表 → 勾选「行号列标」
页眉页脚 插入 → 页眉和页脚，可插入页码、日期
🧠 速记口诀
「打印先设标题行，多页表头不丢失；宽表缩放打一页，分页预览手动调」

07 公式与函数基础

公式结构：一切从等号开始

公式以 = 开头，由单元格引用、运算符、常量、函数组成。Excel 会实时计算并显示结果，改引用单元格结果自动更新（这是与「粘贴死值」的本质区别）。 

=A1+B1          引用 + 运算符
=A1*B1-C1/2      运算符优先级：先乘除后加减
=SUM(A1:A10)     函数：SUM 求和
=(A1+B1)*2       括号优先，优先运算

运算符优先级（从上到下）

优先级 运算符 说明
1 : , 空格 区域 / 联合 / 交叉引用
2 - 负号
3 % 百分比
4 ^ 乘幂
5 * / 乘除
6 + - 加减
7 & 文本连接
8 = <> <= >= 比较

相对引用 vs 绝对引用（必考必会）

写法 含义 向下拖拽效果
A1 相对引用，随位置变化 A2、A3… 跟着变
$A$1 绝对引用，行列都锁死 永远是 A1
$A1 列锁定，行可变 $A2、$A3…（列不变）
A$1 行锁定，列可变 横向拖时行不变
🧠 速记口诀
「美元锁哪里，哪里就不动；F4 循环切，三种引用一键换」——编辑公式时选中引用按 F4：A1 → $A$1 → A$1 → $A1 循环切换。

名称管理器：给区域起名字

  • 公式 → 名称管理器 → 新建；或选中区域后在名称框直接输入名字
  • 命名后公式可写 =SUM(销售额)，可读性大增
  • 快捷键：Ctrl+F3 打开名称管理器
  • 「公式 → 根据所选内容创建」可批量按表头命名

常见错误值速查

错误 原因 排查方向
##### 列太窄（或负日期） 拉宽列
#DIV/0! 除以 0 或空单元格 用 IFERROR 兜底
#N/A 查找不到匹配值 检查 VLOOKUP 参数
#VALUE! 参数类型错误（文本当数字算） 检查引用单元格格式
#REF! 引用的单元格被删除 撤销 / 改公式
#NAME? 函数名拼错或名称不存在 检查拼写

08 常用函数实战

函数 = =函数名(参数1, 参数2, …)。下面按家族分组，先记「每个函数是干嘛的 + 参数顺序」，具体语法随时按 F1 或点编辑栏 fx 查看。

逻辑家族：IF / IFS / AND / OR / IFERROR

函数 作用 示例
IF(条件, 是, 否) 条件判断，返回两个值之一 =IF(A1>=60,"及格","不及格")
IFS(条件1,值1,…) 多条件依次判断（替代嵌套 IF） =IFS(A1>=90,"优",A1>=80,"良","差")
AND(条件…) / OR(…) 所有成立 / 任一成立，返回 TRUE/FALSE =IF(AND(A1>0,B1>0),"都正","有非正")
IFERROR(公式, 兜底) 公式出错时返回兜底值 =IFERROR(A1/B1,"除数不能为0")

数学与统计家族：SUM 系 / COUNT 系 / 最值

函数 作用 示例
SUM(区域) 求和 =SUM(A1:A10)
SUMIF(条件区, 条件, 求和区) 单条件求和（注意三参顺序） =SUMIF(B:B,"华东",C:C)
SUMIFS(求和区, 条件区1, 条件1, …) 多条件求和（求和区放最前！） =SUMIFS(C:C,A:A,"华东",B:B,">100")
COUNT(区域) / COUNTA 数数字个数 / 数非空个数 =COUNTA(A:A) 数有几行有内容
COUNTIF / COUNTIFS 条件计数（单/多条件） =COUNTIF(B:B,">60")
AVERAGE / AVERAGEIFS 平均值 / 条件平均值 =AVERAGEIFS(C:C,A:A,"华东")
MAX / MIN / LARGE / SMALL 最大 / 最小 / 第 N 大 / 第 N 小 =LARGE(A:A,2) 第二高
ROUND(数, 位数) 四舍五入（还有 ROUNDUP/ROUNDDOWN） =ROUND(A1*0.1,2)
RANK(值, 区域) 排名 =RANK(A1,$A$1:$A$10) 区域要绝对引用
⚠️ 避坑提示
SUMIF 和 SUMIFS 参数顺序相反：SUMIF 是「条件区, 条件, 求和区」，SUMIFS 是「求和区, 条件区1, 条件1, …」。背口诀：「S 在后面的（SUMIFS），求和区打头」。

查找引用家族：VLOOKUP 和它的伙伴

=VLOOKUP(查找值, 表格区域, 第几列, 0)
例：根据 A2 的员工号，在 D:E 两列里找，返回第 2 列（姓名）
=VLOOKUP(A2, D:E, 2, 0)      第 4 参 0 = 精确匹配，必写！

=INDEX(返回区域, MATCH(查找值, 查找区域, 0))
例：根据 B1 的名字，在 B 列找行号，返回 A 列对应值
=INDEX(A:A, MATCH(B1, B:B, 0))  INDEX+MATCH 万能组合，可向左查
  • VLOOKUP 三要求：查找值必须在区域第一列；区域从左到右数列号；第 4 参写 0 精确匹配
  • VLOOKUP 局限：只能向右查。要向左查 / 多列返回，用 INDEX + MATCH
  • XLOOKUP（新版本）：=XLOOKUP(查找值, 查找列, 返回列)，无方向限制，还带找不到时的兜底参数

文本与日期家族

函数 作用 示例
LEFT / RIGHT / MID 取左 / 取右 / 取中间 =MID(A2,2,3) 从第 2 位取 3 个
LEN(文本) 字符长度 =LEN(A2)
TRIM(文本) 去掉多余空格 =TRIM(A2)
SUBSTITUTE(文本,旧,新) 替换指定文本 =SUBSTITUTE(A2,"-","") 去横杠
TEXT(值, 格式) 按格式转文本（结果不可计算） =TEXT(A2,"yyyy-mm-dd")
CONCAT / 文本连接符 & 拼接文本 =A2&"-"&B2
TODAY() / NOW() 今天日期 / 当前日期时间（易变） =TODAY()
DATEDIF(起,止,"y"/"m"/"d") 相隔年 / 月 / 天数 =DATEDIF(B2,TODAY(),"y") 年龄
WEEKDAY(日期,2) 星期几（第 2 参 2 = 周一=1） =WEEKDAY(A2,2)
🧠 速记口诀
「IF 判断，SUM 求和，VLOOKUP 查找；COUNT 数数，TRIM 去空格，TEXT 改格式；三兄弟 AND OR NOT 配 IF 用」——函数不求一次记全，记住「家族 + 用途 + 参数顺序」即可。

09 排序与筛选

排序三招

  • 单列排序：选中列内任意单元格 → 开始 → 升序/降序（不用全选列！）
  • 多列排序：选中数据区 → 数据 → 排序 → 添加条件（主要/次要关键字）
  • 自定义排序：排序 → 次序 → 自定义序列（如按「低级→高级」排）
⚠️ 避坑提示
排序前确保整片数据都被选中（或选中区域内任意单元格再排），否则只排一列，行数据就错位了。合并单元格是排序的隐形杀手——先取消合并。

筛选：只看想看的行

  • 开启筛选：选中表头 → 数据 → 筛选；或 Ctrl+Shift+L
  • 按条件筛：点表头下拉箭头 → 数字/文本/日期筛选（大于、包含、介于…）
  • 搜索筛选：下拉框顶部搜索框直接输入关键字
  • 按颜色筛：按单元格颜色 / 字体颜色筛选（下拉 → 按颜色筛选）
  • 筛选求和：选中筛选结果区域，状态栏自动显示可见行的求和

高级筛选：把筛选条件写成表

  1. 在空白处写条件区：第一行放字段名，下面放条件值（同行 = 且，不同行 = 或）
  2. 数据 → 高级 → 列表区域选数据，条件区域选条件区
  3. 勾选「将筛选结果复制到其他位置」，指定输出区域
条件区示例（放在 F1:H3）：
部门      销售额    年龄
华东      >1000
华南      >2000
→ 华东且销售额>1000，或 华南且销售额>2000（同行为且，跨行为或）
🧠 速记口诀
「Ctrl+Shift+L 开筛选；排序先选中区域，防止行错位；高级筛选条件区，同行且跨行或」

10 数据透视表

透视表是什么：一拖一拽出报表

数据透视表能在几秒内把几千行明细汇总成报表，是 Excel 数据分析的第一生产力。核心是「拖字段」：把字段拖到四个区域，报表自动生成。

四大区域（灵魂）

区域 作用 放什么
筛选 整个报表的过滤器 年份、区域
行 按行分组（报表的「行标签」） 产品、部门
列 按列分组（报表的「列标签」） 季度、渠道
值 要汇总的数值（求和/计数/平均） 销售额、订单数

创建与常用操作

  1. 选中明细数据任意单元格 → 插入 → 数据透视表 → 确定（自动识别整表）
  2. 右侧字段列表勾选字段，或拖到四个区域
  3. 改汇总方式：值字段右键 → 值字段设置 → 求和/计数/平均值
  4. 值显示方式：右键 → 值显示方式 → 总计百分比 / 行汇总百分比
  5. 分组：日期字段右键 → 组合 → 按月/季度/年；数值字段可设区间分组
  6. 切片器：分析 → 插入切片器 → 可视化筛选按钮（可多选、联动）
  7. 刷新：数据变化后右键 → 刷新；Alt+F5 刷新，Ctrl+Alt+F5 全部刷新
⚠️ 避坑提示
① 透视表不会自动刷新，源数据改了必须手动刷新；② 在明细后面加新列透视表看不到，要「更改数据源」扩大区域；③ 双击透视表数字能展开明细（钻取），这是核对数据的神器。
🧠 速记口诀
「行是维度列是维度，值放度量默认求和；右键刷新记心间，双击数字看明细」

11 图表可视化

图表选型：先想「要表达什么」

目的 推荐图表 说明
对比大小 柱状图 / 条形图 分类多时用条形（横着）
看趋势 折线图 时间序列首选
看占比 饼图 / 环形图 类别≤5 个才用饼图
看相关性 散点图 两列数值的关系
看分布 直方图 / 箱线图 数据分布形态
数据条内嵌 迷你图（插入 → 迷你图） 单元格内微型折线

图表三件套：标题 / 数据标签 / 坐标轴

  • 快速加元素：选中图表 → 右上角「+」按钮 → 勾选数据标签、图表标题、坐标轴标题
  • 组合图：插入 → 组合图 → 自定义组合（如销售额柱状 + 增长率折线，双轴）
  • 改数据：右键 → 选择数据，或直接拖动图表周围蓝框调整源区域
  • 美化：图表设计 → 更改颜色 / 图表样式；选中单个系列可改填充色
🧠 速记口诀
「对比用柱、趋势用线、占比用饼、相关用散；标题标签不能少，图表让人一眼懂」

12 条件格式与数据验证

条件格式：让数据「自己说话」

  • 突出显示：大于/小于/等于/文本包含/重复值 → 标色
  • 数据条：单元格内横向条形，大小直观对比
  • 色阶：红黄绿渐变，看分布
  • 图标集：▲●▼ 图标标记高低
  • 公式规则：新建规则 → 使用公式（可跨列整行标色）
公式规则示例：给整行标色（先选中 A2:F100，再新建规则）
=$C2>1000
关键：行号用相对引用（$C2），列用绝对（$C）——规则会应用到每一行
  • 管理规则：条件格式 → 管理规则 → 查看优先级、作用范围、删除
  • 清除：条件格式 → 清除规则 → 清除整个工作表的规则

数据验证：给输入「立规矩」

验证类型 用途 设置
序列（下拉列表） 限定只能选固定选项 允许：序列；来源：男,女 或引用区域
整数 / 小数 限定数值范围 介于 0 到 100
日期 限定日期范围 介于 2026/1/1 到 2026/12/31
自定义公式 复杂规则 =A2<>"" 非空
  • 圈释无效数据：数据 → 数据验证 → 圈释无效数据（画红圈标出不合规的）
  • 输入提示：数据验证 → 输入信息（鼠标放上去显示提示）
  • 错误警告：出错时弹窗拦截（停止/警告/信息三档）
🧠 速记口诀
「条件格式先选中区域，公式规则锁列不锁行；数据验证建下拉，圈释无效一目了」

13 数据处理技巧

分列：一列拆多列（治乱格式神器）

  1. 选中要拆的列 → 数据 → 分列
  2. 按分隔符号拆（逗号、空格、制表符、自定义）或按固定宽度拆
  3. 第三步可顺手把列格式设为文本/日期（治「文本型数字」的终极方案）
⚠️ 避坑提示
分列会覆盖右侧相邻列！右侧有数据时先插入空列。日期乱码（如 2026.9.1、20260901）先用分列 → 日期格式（YMD）一步治好。

去重：删除重复项 / 提取唯一值

  • 删除重复项：数据 → 删除重复项（直接删行，慎用，先备份或复制一份）
  • 提取唯一值：数据 → 高级筛选 → 勾选「选择不重复的记录」→ 复制到新位置
  • 标出重复：条件格式 → 突出显示 → 重复值

查找替换与通配符

通配符 含义 示例
* 任意多个字符 查找「张*」= 所有张开头
? 任意单个字符 查找「张?」= 张 + 任意 1 字
~ 转义通配符本身 查找「*」用 ~*
  • 查找替换快捷键：Ctrl+F 查找，Ctrl+H 替换
  • 整列替换：选中列再 Ctrl+H，只在选中范围替换
  • 替换时可点击「选项 → 单元格匹配」防止误伤（如把 12 换成 13 会把 123 也改了）

定位条件（F5 / Ctrl+G）：选中特殊单元格

定位目标 场景
空值 批量补 0 / 补「无」/ 标色空单元格
公式 把所有公式标色，检查计算逻辑
常量 反向找哪些是硬编码值
可见单元格 筛选后只想复制可见部分（Alt+; 同效）
差异单元格 两列对比找不同（Ctrl+\ 同效）
🧠 速记口诀
「分列治乱格式，F5 定位选中空；Alt+; 只选可见，两列对比 Ctrl+\」

14 高级函数与数组

INDEX + MATCH：比 VLOOKUP 更自由的查找

  • MATCH(查找值, 区域, 0) → 返回位置（第几行/第几列）
  • INDEX(区域, 行号, 列号) → 按位置取值
  • 组合 = 「先找位置，再取该位置的值」，可向左查、跨表查、反向查
二维查表：根据产品名(行)和季度(列)交叉取数
=INDEX(B2:E10, MATCH(H2, A2:A10, 0), MATCH(I2, B1:E1, 0))
—— 行方向找产品，列方向找季度，交叉点即结果

OFFSET 与 INDIRECT：动态区域

函数 作用 示例
OFFSET(基准, 行偏移, 列偏移, 高, 宽) 从基准点移动并取区域（易失性函数，慎用） =SUM(OFFSET(A1,0,0,10,1)) 前 10 行
INDIRECT("引用文本") 把文本变成引用（易失性，公式会变慢） =SUM(INDIRECT("B"&A1)) B 列 A1 行到某处
CHOOSE(n, 值1, 值2,…) 按下标取值 =CHOOSE(2,"一","二","三") → 二

SUMPRODUCT：数组计算一把梭

多条件计数 / 求和的万能写法（无需 Ctrl+Shift+Enter）
=SUMPRODUCT((A:A="华东")*(B:B>100))          计数：华东且>100 的行数
=SUMPRODUCT((A:A="华东")*(B:B>100)*C:C)      求和：满足条件的 C 列合计
=SUMPRODUCT((A:A="华东")*(B:B="手机")*C:C)    双条件求和
⚠️ 避坑提示
SUMPRODUCT 里条件列不能整列引用（A:A 可，但整列会算全表 104 万行变慢），建议用 A2:A1000 精确区域。(条件)*(条件) 是相乘 = 且；想「或」用 (条件1)+(条件2)。

新函数（365 版本福利）

  • XLOOKUP：查找无方向限制、带兜底值
  • FILTER(区域, 条件)：一键筛选出所有匹配行（动态数组）
  • UNIQUE(区域)：提取唯一值（替代高级筛选）
  • SORT / SORTBY：公式排序，不破坏原表
  • TEXTSPLIT / TEXTJOIN：文本拆分与合并
🧠 速记口诀
「INDEX 定坐标，MATCH 找行号；SUMPRODUCT 数组算，条件相乘是且；新函数 FILTER UNIQUE，动态数组真香」

15 数据分析工具

模拟运算表：改一个变量看所有结果

  1. 把公式放在首行（如 =B1*0.05 的还款额公式）
  2. 首列竖着放一列「利率假设值」
  3. 选中整个区域 → 数据 → 模拟分析 → 模拟运算表 → 输入引用单元格

双变量：首行放第二个变量，首列放第一个变量，交叉区域就是结果矩阵——银行算房贷、销售算定价常用。

规划求解：求最优解

  • 启用：文件 → 选项 → 加载项 → 转到 → 勾选「规划求解加载项」
  • 用法：数据 → 规划求解 → 设置目标单元格（最大化/最小化）、可变单元格、约束条件
  • 经典场景：有限预算下最大化利润、产能分配、排班

Power Query：数据清洗流水线

  • 数据 → 从表格/区域 → 进入 Power Query 编辑器
  • 常用清洗：删除列、筛选行、拆分列、替换值、合并查询、逆透视
  • 每次操作都记录成步骤，源数据更新后右键 → 刷新即可重跑全部清洗
  • 关闭并上载 → 得到一张可刷新的干净表
📌 一句话理解
Power Query 是「数据的厨房」：切菜（分列）、洗菜（去空）、挑菜（筛选）都在这做，做完端上桌（上载），以后菜变了（刷新）重做一遍，步骤不用重写。

分析工具库：一键统计

  • 启用：文件 → 选项 → 加载项 → 分析工具库
  • 数据 → 数据分析 → 描述统计 / 直方图 / 相关系数 / 回归
  • 适合快速出统计量：均值、标准差、中位数、偏度
🧠 速记口诀
「模拟运算表公式摆首行，规划求解目标可变约束三件套；Power Query 洗数据，刷新重跑不用愁」

16 宏与 VBA 入门

录制宏：让 Excel 替你记住操作

  1. 确保「开发工具」选项卡可见：文件 → 选项 → 自定义功能区 → 勾选开发工具
  2. 开发工具 → 录制宏 → 起名、设快捷键（可选）→ 开始操作
  3. 操作完点「停止录制」——以后一键重放这套操作
⚠️ 避坑提示
带宏的文件要存成 .xlsm（启用宏的工作簿），存 .xlsx 宏会丢失。打开他人宏文件注意安全——文件 → 选项 → 信任中心 → 宏设置。

VBA 快速上手：三个关键词

Sub 我的第一个宏()
    Range("A1").Value = "你好，Excel"   给 A1 写值
    Range("A1").Font.Bold = True        加粗
    Range("A1:B10").Interior.Color = RGB(198, 239, 206) 填充浅绿
    MsgBox "完成！"                      弹窗提示
End Sub
概念 说明 示例
Sub … End Sub 过程（宏）的开始与结束 Sub 名字() … End Sub
Range 操作单元格/区域 Range("A1"), Range("A1:B10")
Cells(行, 列) 按行列号访问 Cells(1,1) = Range("A1")
For Each … Next 遍历循环 For Each c In Range("A1:A10")
If … Then … End If 条件判断 If x > 0 Then … End If

实用小宏：批量做表

一键新建 12 个月份工作表
Sub 新建月份表()
    Dim i As Integer
    For i = 1 To 12
        Worksheets.Add After:=Sheets(Sheets.Count)
        ActiveSheet.Name = i & "月"
    Next i
End Sub
🧠 速记口诀
「录制是入门，改代码是进阶；Sub 开头 End 结尾，Range 指哪打哪，For Each 循环走天下」

17 常见坑与避坑指南

十大经典坑（症状 → 原因 → 解法）

# 症状 原因 解法
1 筛选/排序后数据错乱 有合并单元格 取消合并，用跨列居中
2 VLOOKUP 返回 #N/A 漏写第 4 参 0（近似匹配）或查找列有空格 写 0；TRIM 清洗数据
3 求和为 0 / 统计不到 文本型数字（左上角绿三角） 分列 → 常规；或 *1 乘一下
4 公式结果不更新 计算模式设为手动 公式 → 计算选项 → 自动；F9 重算
5 日期变成 #### 或乱码 列太窄 / 文本格式日期 拉宽列；分列转日期
6 粘贴后格式全乱 直接 Ctrl+V 带格式 粘贴 → 值 / 只保留数值
7 透视表数据不对 忘记刷新 右键刷新；加列后改数据源
8 条件格式错位 作用范围选错 / 相对引用错 管理规则检查区域
9 表格莫名变大、卡顿 误按 Ctrl+End 发现几百万空行 删多余行、Ctrl+S 保存复位
10 打开文件提示损坏/宏丢失 宏存成了 xlsx 另存为 xlsm

习惯层面的避坑心法

  • 原始数据永远留一份副本，别在原始表上直接改
  • 表头规范：一行表头、无合并、无空行、数据连续——这是透视表/公式的地基
  • 重要操作前按一次 Ctrl+S；大胆用撤销 Ctrl+Z
  • 公式给别人看之前：把文本型数字、#N/A 都处理干净
🧠 速记口诀
「合并单元格是坑王，VLOOKUP 记得写 0；文本数字先分列，透视表常刷新；原始数据留副本，表头规范地基牢」
