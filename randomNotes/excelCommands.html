01 逻辑函数

逻辑函数的核心是「判断」：条件成立返回什么、不成立返回什么。所有返回 TRUE / FALSE 的函数都能直接配合 IF 使用。

函数 语法 / 说明 示例
IF IF(条件, 真值, 假值) 基础判断 =IF(A1>=60,"及格","不及格")
IFS IFS(条件1,值1,条件2,值2,…) 多条件依次判断，替代嵌套 IF =IFS(A1>=90,"优",A1>=80,"良",A1>=60,"中","差")
IFERROR IFERROR(公式, 出错时返回值) 公式错误时兜底 =IFERROR(A1/B1,"除数为0")
IFNA IFNA(公式, 值) 只拦截 #N/A，其他错误照常显示 =IFNA(VLOOKUP(A1,B:C,2,0),"无此编号")
AND AND(条件1,…) 全部成立才 TRUE =AND(A1>0,B1>0)
OR OR(条件1,…) 任一成立即 TRUE =OR(A1="华东",B1="华东")
NOT NOT(条件) 取反 =NOT(A1="停用")
SWITCH SWITCH(值, 匹配1, 结果1,…, 默认) 精确匹配多分支 =SWITCH(A1,"A","优","B","良","其他")
TRUE / FALSE 返回逻辑值本身 =IF(TRUE,"永远成立","不会到这")
🧠 速记口诀
「IF 单条件，IFS 多条件，IFERROR 兜错误；AND 全真、OR 一真、NOT 反着来」

02 数学与三角函数

求和、取整、舍入、随机数——最常用的一族函数。重点记 SUMIF / SUMIFS 的参数顺序差异。

函数 语法 / 说明 示例
SUM SUM(数1,数2,…) 求和 =SUM(A1:A10)
SUMIF SUMIF(条件区, 条件, 求和区) 单条件求和 =SUMIF(B:B,"华东",C:C)
SUMIFS SUMIFS(求和区, 条件区1, 条件1, …) 多条件求和，求和区在前 =SUMIFS(C:C,A:A,"华东",B:B,">100")
SUMPRODUCT SUMPRODUCT(数组1,数组2,…) 乘积求和 / 万能多条件计数 =SUMPRODUCT((A:A="华东")*(B:B>100))
ROUND ROUND(数, 位数) 四舍五入 =ROUND(A1,2)
ROUNDUP ROUNDUP(数, 位数) 向上（远离零）舍入 =ROUNDUP(3.01,0) → 4
ROUNDDOWN ROUNDDOWN(数, 位数) 向下（靠近零）舍入 =ROUNDDOWN(3.99,0) → 3
INT INT(数) 向下取整（负数注意！） =INT(-3.5) → -4
TRUNC TRUNC(数) 截断小数（不四舍五入） =TRUNC(3.99) → 3
MOD MOD(被除数, 除数) 取余数 =MOD(10,3) → 1
ABS ABS(数) 绝对值 =ABS(-5) → 5
POWER POWER(底, 幂) 乘幂（或 ^ 运算符） =POWER(2,10) → 1024
SQRT SQRT(数) 平方根 =SQRT(16) → 4
RAND RAND() 0~1 随机小数（易失，F9 重算变） =RAND()
RANDBETWEEN RANDBETWEEN(最小, 最大) 区间随机整数 =RANDBETWEEN(1,100)
CEILING / FLOOR CEILING(数, 倍数) 向上/向下取倍数 =CEILING(4.2,0.5) → 4.5
SUM 系列特殊 SUBTOTAL(9,区域) 忽略被筛选隐藏的行求和（9=求和，109 忽略手工隐藏） =SUBTOTAL(9,A1:A100)
⚠️ 避坑提示
SUMIF 是「条件区, 条件, 求和区」，SUMIFS 是「求和区, 条件区1, 条件1, …」——带 S 的求和区打头。筛选后想「只算看得见的行」，用 SUBTOTAL(9,…) 别用 SUM。

03 统计函数

数个数、算平均、找最大最小、排名——统计家族记牢「COUNT 数的是数字，COUNTA 数的是非空」这一条就不容易混。

函数 语法 / 说明 示例
COUNT COUNT(区域) 只数数字个数 =COUNT(A1:A100)
COUNTA COUNTA(区域) 数非空单元格（文本也算） =COUNTA(A:A)
COUNTBLANK COUNTBLANK(区域) 数空单元格 =COUNTBLANK(A:A)
COUNTIF COUNTIF(区域, 条件) 单条件计数 =COUNTIF(B:B,">60")
COUNTIFS COUNTIFS(区域1, 条件1, …) 多条件计数 =COUNTIFS(A:A,"华东",B:B,">60")
AVERAGE AVERAGE(区域) 平均值（忽略文本） =AVERAGE(A1:A10)
AVERAGEIF AVERAGEIF(条件区, 条件, 平均区) 单条件平均 =AVERAGEIF(B:B,"华东",C:C)
AVERAGEIFS AVERAGEIFS(平均区, 条件区1, 条件1, …) 多条件平均 =AVERAGEIFS(C:C,A:A,"华东")
MAX / MIN MAX(区域) / MIN(区域) 最大 / 最小 =MAX(A1:A10)
MAXIFS / MINIFS MAXIFS(区域, 条件区, 条件) 条件最大/最小 =MAXIFS(C:C,A:A,"华东")
LARGE / SMALL LARGE(区域, k) 第 k 大 / 第 k 小 =LARGE(A:A,2)
RANK RANK(值, 区域) 排名（区域要绝对引用） =RANK(A1,$A$1:$A$10)
MEDIAN MEDIAN(区域) 中位数（抗极端值） =MEDIAN(A1:A10)
MODE MODE(区域) 众数（出现最多） =MODE(A1:A10)
STDEV / VAR STDEV(区域) 标准差 / VAR 方差（离散度） =STDEV(A1:A10)
PERCENTILE PERCENTILE(区域, k) 第 k 百分位 =PERCENTILE(A:A,0.9) 90 分位
🧠 速记口诀
「COUNT 数数字，COUNTA 数非空；IF 加在函数后就是条件版；RANK 区域要锁 $，LARGE 第几大」

04 查找与引用

面试和实战都逃不开的一族。VLOOKUP 用着最顺手，但 INDEX + MATCH 才是万能解，新版本还有 XLOOKUP 一统江湖。

函数 语法 / 说明 示例
VLOOKUP VLOOKUP(查找值, 区域, 列号, 0) 垂直查找，第 4 参必写 0 =VLOOKUP(A2,D:E,2,0)
HLOOKUP HLOOKUP(查找值, 区域, 行号, 0) 水平查找 =HLOOKUP(B1,A1:D2,2,0)
XLOOKUP XLOOKUP(查找值, 查找列, 返回列, [未找到值]) 无方向限制 =XLOOKUP(A2,B:B,C:C,"无")
LOOKUP LOOKUP(查找值, 查找列, 返回列) 旧式查找（近似，慎用） =LOOKUP(85,A:A,B:B)
INDEX INDEX(区域, 行号, [列号]) 按位置取区域中的值 =INDEX(B2:E10,3,2)
MATCH MATCH(查找值, 区域, 0) 返回位置（第 3 参 0 = 精确） =MATCH("手机",A:A,0)
INDEX+MATCH INDEX(返回区, MATCH(查找值, 查找区, 0)) 万能双向查找 =INDEX(A:A,MATCH(B1,B:B,0))
CHOOSE CHOOSE(序号, 值1, 值2, …) 按下标取值 =CHOOSE(WEEKDAY(A1,2),"一","二","三","四","五","六","日")
INDIRECT INDIRECT("引用文本") 文本转引用（易失函数） =SUM(INDIRECT("B"&A1&":B"&A2))
OFFSET OFFSET(基准, 行偏, 列偏, [高], [宽]) 动态区域（易失） =SUM(OFFSET(A1,0,0,10,1))
TRANSPOSE TRANSPOSE(区域) 行列转置（需数组输入） =TRANSPOSE(A1:C3)
ROW / COLUMN ROW([单元格]) 返回行号 / 列号 =ROW(A5) → 5
⚠️ 避坑提示
VLOOKUP 三坑：① 查找值必须在区域第一列；② 第 4 参漏写 0 会近似匹配出奇怪结果；③ 查找值或数据带空格会查不到——先 TRIM 再查。

05 文本函数

清洗和拼接文本全靠这一族。牢记「提取三剑客 LEFT / RIGHT / MID」「替换两兄弟 SUBSTITUTE / REPLACE」。

函数 语法 / 说明 示例
LEFT LEFT(文本, [位数]) 从左边取 =LEFT("ABC123",3) → ABC
RIGHT RIGHT(文本, [位数]) 从右边取 =RIGHT("ABC123",2) → 23
MID MID(文本, 起始位, 位数) 从中间取 =MID("ABC123",2,3) → BC1
LEN LEN(文本) 字符个数 =LEN("你好AB") → 4
FIND FIND(找什么, 在哪找, [起始]) 找位置（区分大小写） =FIND("@","a@b") → 2
SEARCH SEARCH(找什么, 在哪找) 找位置（不区分大小写，支持通配符） =SEARCH("B","abc") → 2
SUBSTITUTE SUBSTITUTE(文本, 旧, 新, [第几次]) 替换全部/指定次 =SUBSTITUTE(A1,"-","") 去横杠
REPLACE REPLACE(文本, 起始位, 位数, 新文本) 按位置替换 =REPLACE("13812345678",4,4,"****") 脱敏
TRIM TRIM(文本) 去首尾及中间多余空格 =TRIM(" a b ") → "a b"
CONCAT / CONCATENATE CONCAT(文本1,文本2,…) 拼接；& 运算符更快 =A2&"-"&B2
TEXTJOIN TEXTJOIN(分隔符, TRUE, 区域) 用分隔符合并区域（忽略空） =TEXTJOIN("、",TRUE,A1:A5)
TEXT TEXT(值, "格式") 按格式转文本（结果不可计算） =TEXT(A1,"yyyy年mm月dd日")
VALUE VALUE(文本数字) 文本转数字 =VALUE("123") → 123
UPPER / LOWER / PROPER 转大写 / 小写 / 首字母大写 =UPPER("abc") → ABC
TEXTSPLIT TEXTSPLIT(文本, 分隔符) 拆成多列（新函数） =TEXTSPLIT(A1,",")
CHAR / CODE CHAR(编号) 编号转字符 / CODE 反向 =CHAR(10) 换行符
🧠 速记口诀
「LEFT 左、RIGHT 右、MID 中间；LEN 数长度；TRIM 去空格；拼接用 &，TEXT 改格式」

06 日期与时间

日期在 Excel 里本质是数字（1900-01-01 = 1），所以能直接加减！今天 - 入职日期 = 工作天数。注意 TODAY() 会每天变。

函数 语法 / 说明 示例
TODAY TODAY() 今天日期（每天自动更新） =TODAY()
NOW NOW() 当前日期 + 时间 =NOW()
DATE DATE(年, 月, 日) 拼出日期 =DATE(2026,9,1)
YEAR / MONTH / DAY 提取年 / 月 / 日 =YEAR(A1)
DATEDIF DATEDIF(起始, 结束, "y"|"m"|"d") 间隔年/月/天 =DATEDIF(B2,TODAY(),"y") 年龄
WEEKDAY WEEKDAY(日期, 2) 星期几（2=周一为 1） =WEEKDAY(A1,2)
WEEKNUM WEEKNUM(日期) 一年第几周 =WEEKNUM(A1)
EDATE EDATE(日期, 月数) 加/减 N 个月 =EDATE(A1,3) 3 个月后
EOMONTH EOMONTH(日期, 月数) 月末日期 =EOMONTH(TODAY(),0) 本月最后一天
WORKDAY WORKDAY(起始, 天数) 加 N 个工作日（跳过周末） =WORKDAY(TODAY(),10)
NETWORKDAYS NETWORKDAYS(起始, 结束) 两日期间工作日数 =NETWORKDAYS(A1,A2)
HOUR / MINUTE / SECOND 提取时 / 分 / 秒 =HOUR(NOW())
TIME TIME(时, 分, 秒) 拼出时间 =TIME(18,30,0)
ISOWEEKNUM ISOWEEKNUM(日期) ISO 周数（周一为一周开始） =ISOWEEKNUM(A1)
⚠️ 避坑提示
① 日期被存成文本（左对齐）就不能加减了，用分列 → 日期转换；② DATEDIF 是隐藏函数，没有函数向导提示，但能用；③ 想输入固定的今天日期用 Ctrl+;，别用 TODAY()（会变）。

07 数据库与信息函数

数据库函数（D 开头）按「条件区域」统计——条件区要自己搭一个带表头的小表。信息函数（IS 开头）用来判断数据类型，常和 IF 配合做「格式体检」。

函数 语法 / 说明 示例
DSUM DSUM(数据区, 字段列, 条件区) 按条件区求和 =DSUM(A1:D100,"销售额",F1:G2)
DCOUNT / DCOUNTA 按条件区数数字 / 数非空 =DCOUNTA(A1:D100,"姓名",F1:G2)
DAVERAGE 按条件区求平均 =DAVERAGE(A1:D100,"销售额",F1:G2)
DMAX / DMIN 按条件区求最大 / 最小 =DMAX(A1:D100,"销售额",F1:G2)
ISNUMBER ISNUMBER(值) 是不是数字（查文本型数字） =IF(ISNUMBER(A1),"数字","文本")
ISTEXT / ISBLANK 是不是文本 / 是不是空 =ISBLANK(A1)
ISERROR / ISERR 是否任意错误 / 是否非 #N/A 错误 =IF(ISERROR(A1),"有错","OK")
ISLOGICAL 是不是逻辑值 TRUE/FALSE =ISLOGICAL(A1)
CELL CELL("info_type", [单元格]) 单元格信息（格式/地址等） =CELL("address")
ERROR.TYPE ERROR.TYPE(错误值) 错误值对应编号 =ERROR.TYPE(A1) #N/A → 7
N / T N(值) 转数字 / T(值) 转文本 =N(TRUE) → 1
NA NA() 主动制造 #N/A =IF(A1="",NA(),A1)
🧠 速记口诀
「D 开头按条件区统计，条件区要带表头；IS 开头做体检，配上 IF 自动判」

08 财务函数

算房贷、算投资回报的专用函数。记住现金流符号约定：流出为负、流入为正，参数就能摆对。

函数 语法 / 说明 示例
PMT PMT(利率, 期数, 现值) 等额还款额（房贷月供） =PMT(4.9%/12, 360, 1000000) 月供
FV FV(利率, 期数, 每期投入) 终值（定投未来值） =FV(5%/12, 120, -1000)
PV PV(利率, 期数, 每期回收) 现值（反推现在值多少） =PV(5%, 10, -10000)
RATE RATE(期数, 每期, 现值) 反推利率 =RATE(12, -1000, 10000)
NPER NPER(利率, 每期, 现值) 反推期数（多久还完） =NPER(1%, -1000, 50000)
IRR IRR(现金流区域) 内部收益率（项目回报率） =IRR(B2:B10)
NPV NPV(折现率, 现金流) 净现值（>0 项目可行） =NPV(10%, B2:B10)
SLN SLN(原值, 残值, 年限) 直线折旧 =SLN(100000, 10000, 5)
DB / DDB DB(原值, 残值, 年限, 期) 余额递减折旧 =DB(100000,10000,5,1)
XIRR / XNPV 带日期的 IRR / NPV（现金流日期不均） =XIRR(B2:B10,A2:A10)
🧠 速记口诀
「PMT 月供、FV 未来、PV 现值、RATE 反推利率；IRR 看项目回报，现金流流出记负」

10 数据功能区命令

「数据」选项卡是数据处理的指挥中心，下面是每个命令的用途与使用时机。

命令 位置 用途 / 时机
分列 数据 → 分列 一列拆多列；治文本型数字、日期乱码（按分隔符 / 固定宽度）
删除重复项 数据 → 删除重复项 直接删掉重复行（选多列 = 组合判重；操作前备份）
高级筛选 数据 → 高级 条件区筛选、提取唯一值（勾选「选择不重复的记录」）
合并计算 数据 → 合并计算 把多个区域按行/列标签汇总（求和/平均/计数）
模拟分析 数据 → 模拟分析 单变量求解（倒推值）、模拟运算表（假设矩阵）、方案管理器
预测工作表 数据 → 预测工作表 基于历史数据一键生成未来趋势预测 + 置信区间
关系 / 管理关系 数据 → 关系 在数据模型里建立表间关系（配合透视表多表分析）
数据验证 数据 → 数据验证 限制输入（下拉列表、数值范围、自定义公式）；圈释无效数据
分类汇总 数据 → 分类汇总 按某列分组后自动小计/合计（先排序再分类汇总）
从表格/区域 数据 → 从表格/区域 进入 Power Query 编辑器清洗数据（可刷新重跑）
获取数据 数据 → 获取数据 从文件/数据库/网页/API 导入外部数据
规划求解 数据 → 规划求解（需加载项） 线性规划求最优解：目标 + 可变单元格 + 约束
数据分析 数据 → 数据分析（需分析工具库） 描述统计、直方图、相关系数、回归分析一键出
🧠 速记口诀
「分列治乱、去重防错、高级筛选带条件；验证限输入、模拟分析倒推值、PQ 洗数据」

11 数据透视表命令

透视表是 Excel 的「报表发动机」。下面按「建表 → 配置 → 维护」三个阶段列命令。

14 错误值排查

七个常见错误值：一眼定位问题

错误值 含义 最常见的成因 排查动作
##### 列宽不足 / 负日期 列太窄、日期格式为负 拉宽列；查日期是否异常
#DIV/0! 除以 0 分母为 0 或空单元格 IFERROR 兜底；补分母
#N/A 找不到匹配值 VLOOKUP/查找值不存在或带空格 写 0 精确匹配；TRIM 清洗
#VALUE! 参数类型不对 文本当数字运算、引用错误区域 检查引用单元格是否为文本型数字
#REF! 引用失效 删除了公式引用的行列 撤销删除；重写公式
#NAME? 名称无法识别 函数名拼错、名称未定义 检查拼写；名称管理器
#NULL! 区域交叉为空 引用写错（空格应为冒号） 检查区域运算符

公式排查三板斧

  1. Ctrl+` 切公式视图：一眼看到哪些格是公式、哪些是硬编码，公式异常一目了然
  2. 公式求值：公式 → 公式求值 → 逐步看每步计算结果，定位出错的那一步
  3. 追踪引用：公式 → 追踪引用单元格 → 箭头画出上下游，检查被引用的格子是否正常

易失函数与性能警告

函数 问题 建议
OFFSET / INDIRECT 每次重算都会全部重算，大表明显卡顿 能用 INDEX 就不用 OFFSET
RAND / RANDBETWEEN 每次操作都重新随机，数据会变 需要固定值时粘贴为值
NOW / TODAY 打开文件/重算时更新 要固定日期用 Ctrl+;
整列引用 A:A SUMPRODUCT 等数组函数整列引用极慢 用 A2:A10000 精确区域
循环引用 公式引用自己所在的单元格 状态栏提示循环引用；逐格检查箭头
🚨 循环引用红线
公式引用了自己（A1 里写 =A1+1），Excel 会提示循环引用警告并陷入死循环计算。除非刻意做迭代计算，否则一律禁止——状态栏左下角会显示「循环引用: A1」，点它直达问题单元格。
🧠 速记口诀
「#DIV/0! 查分母、#N/A 查查找、#VALUE! 查类型、#REF! 查删除；Ctrl+` 看公式、求值看步骤、追踪看箭头」
