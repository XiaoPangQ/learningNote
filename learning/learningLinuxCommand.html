易混命令记忆口诀 Mnemonics

把最容易记混的命令做成对照卡，配合上面的全称使用。

df vs du
Disk Free / Disk Usage
df 看文件系统「还剩多少」（横向），du 看目录「实际占了多少」（纵向）。
more vs less
非缩写 / "less is more"
more 只能往下翻；less 上下都能翻、还能搜索。记：少即是多，less 更强。
cat vs tac
conCATenate / TAC（反转）
cat 正序输出，tac 倒序输出——tac 就是 cat 反着写。
su vs sudo
Substitute User / Super User DO
su 整体切换成别人（输对方密码）；sudo 临时借 root 权限（输自己密码）。
chmod vs chown vs chgrp
CHange MODe / OWNer / GRouP
mode 改权限位、owner 改属主、group 改属组。核心动词都是 CHange。
grep / egrep / fgrep
Global RE Print / Extended / Fixed
grep 基础正则，egrep 扩展正则（= grep -E），fgrep 固定字符串（= grep -F）。
kill / killall / pkill
按 PID / 按名字全杀 / 按模式杀
kill 认号（PID），killall 认名全杀，pkill 认模式（可按用户、终端过滤）。
useradd / usermod / userdel
USER ADD / MODify / DELete
加用户、改用户、删用户。后缀 add/mod/del 三兄弟，group 系列同理。
yum vs dnf
Yellowdog Updater Modified / DaNdiFied yum
dnf 就是"更潮的 yum"，RHEL8+ 已默认用 dnf，用法几乎一样。
tar 参数四件套
-c / -x / -t / -v
c=create 建，x=extract 抽出，t=list（table of contents）列，v=verbose 啰嗦。口诀：建抽列啰。
shutdown 三种方式
-h / -r / now
h=halt 停机，r=reboot 重启，now=立刻。例：shutdown -h now 立即关机。
find 三大件
-name / -type / -size
按名找（支持通配）、按类型找（f 文件 d 目录）、按大小找（+100M 大于 100MB）。
netstat / ss 四件套
-t / -u / -l / -n
t=TCP，u=UDP，l=listening 监听，n=numeric 数字显示。组合 -tuln 查端口。
grep vs find
找内容 / 找文件
grep 在文件里"找内容"（按正则），find 在磁盘上"找文件"（按属性）。

使用建议：先记高频必会（★ 标记，约 60 条），再按分类扩展；每学一条新命令，先看一眼它的全称，理解了缩写由来，基本就不用死记了。

部分全称说明：su 官方为 Substitute User（非 Switch User）；dd 无官方全称，Data Definition 是常见说法；grep 源自 ed 的 g/re/p；awk 为三位作者姓氏首字母。
