一份系统化的 Linux 学习笔记，覆盖基础命令、Shell 脚本、系统管理、网络安全到容器运维，适合从零开始逐步进阶。

01 Linux 简介与历史

什么是 Linux

Linux 是一个开源的类 Unix 操作系统内核，由 Linus Torvalds 于 1991 年首次发布。严格来说，Linux 指的是内核；我们日常使用的"Linux 操作系统"实际上是 GNU/Linux——Linux 内核加上 GNU 项目的工具和软件构成的完整操作系统。

发展简史

  1. 1969 — Ken Thompson 和 Dennis Ritchie 在贝尔实验室开发 Unix
  2. 1983 — Richard Stallman 发起 GNU 项目，目标是创建自由的类 Unix 系统
  3. 1991 — Linus Torvalds 在赫尔辛基大学发布 Linux 内核 0.01 版
  4. 1992 — Linux 采用 GPL 许可证，成为自由软件
  5. 1993 — Slackware 和 Debian 发行版诞生
  6. 2000s — Red Hat、SUSE 等商业发行版兴起，Linux 在服务器领域普及
  7. 2010s — Android 基于 Linux 内核，云计算时代 Docker/Kubernetes 爆发
  8. 至今 — Linux 驱动着全球绝大多数服务器、超级计算机和嵌入式设备

常见发行版

发行版 包管理器 特点 适用场景
Ubuntu apt 用户友好、社区庞大 桌面、服务器、云
Debian apt 稳定、自由、社区驱动 服务器、基础系统
CentOS/Rocky dnf/yum RHEL 兼容、企业级稳定 企业服务器
Fedora dnf 前沿技术、Red Hat 试验场 开发者、桌面
Arch pacman 滚动更新、极简、KISS 高级用户、桌面
Alpine apk 极小体积、musl libc 容器、嵌入式
💡 入门建议
初学者推荐从 Ubuntu 开始——文档丰富、社区活跃、遇到问题容易找到答案。等熟悉之后再尝试其他发行版。

02 安装与环境准备

三种方式开始 Linux 之旅

方式一：虚拟机（推荐新手）

使用 VirtualBox 或 VMware 在现有系统中创建虚拟机，不影响主系统。

# 推荐配置
CPU: 2 核以上
内存: 4 GB 以上（建议 8GB）
硬盘: 25 GB 以上
网络: NAT 或桥接模式

方式二：WSL2（Windows 用户）

Windows 10/11 用户可通过 WSL2 在 Windows 中原生运行 Linux。

# 在 PowerShell（管理员）中执行
wsl --install

# 安装指定发行版
wsl --install -d Ubuntu-22.04

# 查看可用发行版
wsl --list --online

方式三：云服务器

租用云服务器（阿里云、腾讯云、AWS 等），通过 SSH 远程连接，最接近真实生产环境。 

# SSH 连接云服务器
ssh user@your_server_ip

# 使用密钥登录（更安全）
ssh -i ~/.ssh/id_rsa user@your_server_ip

终端基础

终端（Terminal）是与 Linux 交互的命令行界面。打开终端后，你会看到命令提示符： 

user@ubuntu:~$
  │     │      │  │
  │     │      │  └─ 当前用户是否为 root（$ 普通用户，# root）
  │     │      └──── 当前目录（~ 表示家目录）
  │     └─────────── 主机名
  └───────────────── 用户名

03 文件系统与目录结构

Linux 目录树

Linux 采用单一目录树结构，一切皆文件。所有存储设备都挂载到这棵树下。

目录 用途
/ 根目录，所有文件系统的起点
/bin 基本用户命令（ls, cp, mv 等）
/sbin 系统管理命令（fdisk, mkfs 等）
/etc 系统配置文件
/home 普通用户家目录
/root root 用户家目录
/var 可变数据（日志、缓存、邮件等）
/tmp 临时文件（重启可能清空）
/usr 用户程序和数据（二级目录树）
/opt 可选第三方软件
/dev 设备文件
/proc 虚拟文件系统，内核和进程信息
/sys 虚拟文件系统，硬件和驱动信息
/mnt / /media 临时挂载点 / 可移动设备挂载
/boot 引导加载程序文件
/lib 系统共享库和内核模块

文件路径

# 绝对路径：从根目录开始
/home/user/documents/report.txt

# 相对路径：相对于当前目录
documents/report.txt      # 当前目录下的 documents
./documents/report.txt    # ./ 表示当前目录（可省略）
../sibling/file.txt       # ../ 表示上一级目录
~/scripts/backup.sh       # ~ 表示当前用户家目录

文件类型

通过 ls -l 第一列的第一个字符判断文件类型：

字符 类型 示例
- 普通文件 文本、二进制、图片
d 目录 文件夹
l 符号链接 快捷方式
c 字符设备 终端、键盘
b 块设备 硬盘、U盘
p 管道文件 进程间通信
s 套接字 网络通信

inode

每个文件都有一个 inode（索引节点），存储文件的元数据（权限、所有者、大小、时间戳、数据块位置等），但不包含文件名。文件名和 inode 的对应关系存在目录中。 

# 查看文件 inode 号
ls -i filename

# 查看文件详细信息
stat filename

5.4 文件权限

ls -l 输出的第一列是权限位，例如 -rwxr-xr--： 

-  rwx  r-x  r--
│  │    │    │
│  │    │    └─── others（其他用户）: 读
│  │    └──────── group（同组用户）: 读+执行
│  └───────────── owner（文件所有者）: 读+写+执行
└──────────────── 文件类型（-=普通文件，d=目录）
权限 字符 数字 文件含义 目录含义
读 r 4 可查看内容 可列出目录内容
写 w 2 可修改内容 可创建/删除/重命名文件
执行 x 1 可作为程序运行 可进入目录（cd） 
# chmod: 修改权限
chmod 755 script.sh     # rwxr-xr-x
chmod 644 file.txt      # rw-r--r--
chmod -R 755 dir/      # 递归修改
chmod u+x file          # 给所有者加执行权限
chmod g-w file          # 去掉同组写权限
chmod o=r file          # 设置其他人只读

# chown: 修改所有者
sudo chown user:group file
sudo chown -R www-data:www-data /var/www/

5.5 特殊权限

权限 数字 作用
SUID 4 以文件所有者身份执行（如 passwd）
SGID 2 以文件所属组身份执行；目录内新建文件继承组
Sticky 1 目录内文件只有所有者能删除（如 /tmp）

5.6 ACL 访问控制

# 更细粒度的权限控制
setfacl -m u:alice:rwx /data/project
setfacl -m g:team:rx /data/project
getfacl /data/project

07 Shell 脚本基础

什么是 Shell

Shell 是命令行解释器，是用户与内核交互的桥梁。常见的 Shell 有 Bash（最通用）、Zsh（功能丰富）、Fish（开箱即用）等。脚本文件通常以 .sh 为扩展名。

第一个脚本

#!/bin/bash
# hello.sh — 第一个 Shell 脚本

echo "Hello, Linux!"
echo "当前时间: $(date)"
echo "当前用户: $USER"
echo "当前目录: $PWD"
# 赋予执行权限并运行
chmod +x hello.sh
./hello.sh

# 或直接用 bash 执行（不需要执行权限）
bash hello.sh

变量

# 定义变量（= 两边不能有空格）
name="Linux"
version=100

# 使用变量
echo $name
echo "${name} ${version}"

# 特殊变量
echo $0      # 脚本名
echo $1      # 第一个参数
echo $#      # 参数个数
echo $@      # 所有参数（独立字符串）
echo $?      # 上条命令退出状态（0=成功）
echo $$      # 当前进程 PID

# 命令替换
today=$(date +%Y-%m-%d)
files=$(ls)

# 算术运算
result=$(( (5 + 3) * 2 ))
echo $result   # 16

条件判断

# if 语句
if [ $1 = "hello" ]; then
    echo "你好!"
elif [ $1 = "bye" ]; then
    echo "再见!"
else
    echo "其他输入"
fi

# 文件测试
if [ -f "/etc/passwd" ]; then echo "文件存在"; fi
if [ -d "/tmp" ]; then echo "目录存在"; fi
if [ -r file ]; then echo "可读"; fi
if [ -w file ]; then echo "可写"; fi
if [ -x file ]; then echo "可执行"; fi

# 数字比较：-eq -ne -gt -lt -ge -le
# 字符串比较：= != -z（空） -n（非空）
# 逻辑：&&（与） ||（或） !（非）

循环

# for 循环
for i in 1 2 3 4 5; do
    echo "Number: $i"
done

for file in *.txt; do
    echo "处理: $file"
done

# C 风格 for
for ((i=0; i<5; i++)); do
    echo $i
done

# while 循环
count=0
while [ $count -lt 5 ]; do
    echo "count=$count"
    ((count++))
done

# 读取文件每一行
while IFS= read -r line; do
    echo "行: $line"
done < input.txt

函数

# 定义函数
greet() {
    local name=$1
    echo "Hello, $name!"
}

# 调用函数
greet "World"

# 返回值（通过 echo + $()）
add() {
    echo $(( $1 + $2 ))
}
result=$(add 3 5)

case 语句

case $1 in
    start)
        echo "启动服务..."
        ;;
    stop)
        echo "停止服务..."
        ;;
    restart)
        echo "重启服务..."
        ;;
    *)
        echo "用法: $0 {start|stop|restart}"
        ;;
esac

8.3 systemd 服务管理

现代 Linux 发行版使用 systemd 作为初始化系统（PID 1），管理系统服务。 

# systemctl: 管理服务
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx
sudo systemctl reload nginx      # 重新加载配置（不中断）
sudo systemctl enable nginx      # 开机自启
sudo systemctl disable nginx     # 取消开机自启
systemctl status nginx           # 查看状态
systemctl is-active nginx        # 是否运行中
systemctl is-enabled nginx       # 是否开机自启
systemctl list-units --type=service  # 列出所有服务
systemctl list-unit-files --type=service  # 列出所有服务文件

自定义 systemd 服务

# /etc/systemd/system/myapp.service
[Unit]
Description=My Application
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/myapp
ExecStart=/opt/myapp/bin/server
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload     # 重新加载服务文件
sudo systemctl enable --now myapp  # 启用并立即启动

8.4 定时任务

# crontab: 编辑定时任务
crontab -e              # 编辑当前用户的定时任务

# * 表示任意，*/n 表示每 n

09 文本处理三剑客

9.1 grep — 文本搜索

# 基本用法
grep "pattern" file.txt
grep -i "pattern" file       # 忽略大小写
grep -r "pattern" dir/       # 递归搜索目录
grep -n "pattern" file       # 显示行号
grep -v "pattern" file       # 反向匹配（排除）
grep -c "pattern" file       # 只输出匹配行数

grep -C 2 "error" log        # 显示匹配行前后各2行

9.2 sed — 流编辑器

# 替换文本
sed 's/old/new/' file           # 替换每行第一个匹配
sed 's/old/new/g' file          # 替换所有匹配
sed 's/old/new/g' -i file     # 直接修改原文件
sed 's/old/new/gi' file         # 忽略大小写
sed 's|/old/path|/new/path|g'  # 用 | 作分隔符避免转义

# 行操作
sed '5d' file                   # 删除第5行
sed '2,5d' file                 # 删除第2-5行
sed '/pattern/d' file          # 删除匹配行
sed '5a new line' file         # 在第5行后追加
sed '5i new line' file         # 在第5行前插入

# 只输出匹配行
sed 's/old/new/p' -n file     # -n 禁止默认输出

# 多个操作
sed -e 's/old/new/g' -e 's/foo/bar/g' file

9.3 awk — 文本分析工具

# 基本结构：pattern { action }
awk '{print $1}' file           # 打印第一列（默认空格分隔）
awk '{print $1, $3}' file       # 打印第1和第3列
awk '{print $NF}' file          # 打印最后一列
awk -F',' '{print $2}' csv     # 指定逗号分隔符
awk 'NR==3' file                # 打印第3行
awk 'NR>1 {print}' file         # 跳过第1行

# 条件过滤
awk '$3 > 100 {print $1, $3}' data

# 内置变量
# NR: 当前行号  NF: 当前行字段数  FS: 输入分隔符  OFS: 输出分隔符

# 统计求和
awk '{sum += $1} END {print sum}' numbers.txt

# 去重统计（类似 sort | uniq -c）
awk '{count[$1]++} END {for(k in count) print k, count[k]}' file

9.4 sort / uniq / cut / tr / wc

# sort: 排序

# uniq: 去重（需先排序）

# tr: 字符转换

17 内核与系统原理

17.1 内核概览

Linux 内核主要由以下子系统组成：

  • 进程管理（scheduler）：CFS 调度器、进程/线程、命名空间
  • 内存管理（MM）：虚拟内存、页表、slab 分配器、OOM killer
  • 文件系统（VFS）：ext4、xfs、btrfs、overlayfs、procfs、sysfs
  • 网络栈：TCP/IP、socket、netfilter、XDP/eBPF
  • 设备驱动：字符设备、块设备、网络设备
  • IPC：管道、信号、消息队列、共享内存、信号量

17.2 系统启动流程

  1. BIOS/UEFI — 硬件自检（POST），查找可引导设备
  2. Bootloader (GRUB) — 加载内核和 initramfs
  3. Kernel — 初始化硬件、挂载根文件系统
  4. init/systemd (PID 1) — 挂载文件系统、启动服务
  5. Target/Runlevel — 进入多用户模式或图形界面
  6. Login — getty/Display Manager 等待用户登录

17.3 内核参数管理

# 查看所有内核参数

# 查看单个参数
sysctl net.ipv4.ip_forward

# 临时修改
sudo sysctl -w net.ipv4.ip_forward=1

# 永久修改（写入 /etc/sysctl.conf 或 /etc/sysctl.d/）
echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.conf

# 常用调优参数

net.core.somaxconn=65535            # 连接队列大小
net.ipv4.tcp_max_syn_backlog=65535  # SYN 队列
fs.file-max=2097152                 # 系统最大文件句柄数

17.6 eBPF 简介

eBPF（extended Berkeley Packet Filter）是 Linux 内核中的虚拟机，允许在不修改内核源码和加载模块的情况下安全地扩展内核功能，广泛用于网络、可观测性和安全领域。

bcc/tools

经典的 eBPF 工具集，包含 execsnoop、opensnoop、biolatency 等。

bpftrace

高级追踪语言，类似 awk/DTrace，一行命令即可编写追踪脚本。

bpftool

内核自带的 eBPF 程序查看和管理工具。

实践建议

  1. 每天用 Linux — 把日常工作环境切到 Linux（WSL2、虚拟机或双系统），不用永远学不会
  2. 读 man 手册 — 遇到命令先 man command，比搜索更准确
  3. 写脚本自动化 — 重复操作三次以上就写成脚本
  4. 搭建个人项目 — 用 Nginx 部署网站、配置防火墙、写备份脚本
  5. 阅读优秀脚本 — GitHub 上找开源项目的 Shell 脚本学习
  6. 考取认证（可选） — LPIC、RHCSA/RHCE 系统检验学习成果
💡 核心心法
Linux 的学习没有捷径，但有方法：多用、多查、多写、多排错。遇到报错不要慌，错误信息本身就是最好的老师。记住：每个 Linux 高手都是从 rm -rf 的教训中成长起来的。
