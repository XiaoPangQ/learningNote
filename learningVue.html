第一篇：入门篇（基础夯实）

1.Vue 是什么

一句话：Vue 是一套用于构建用户界面的渐进式 JavaScript 框架。渐进 = 可以只用核心库，也能逐步引入路由、状态管理等全家桶。

概念 含义 记忆点
声明式渲染 只描述「数据长什么样」，不手动操作 DOM 数据变，视图自动变
组件化 把页面拆成可复用、独立的小块 拼乐高
响应式 数据变化自动驱动视图更新 自动同步
单文件组件 SFC .vue 文件把模板/逻辑/样式封装一体 <template> + <script> + <style>
数据驱动视图，组件拼装页面； 响应式是灵魂，SFC 是容器。

2.快速上手

方式一：CDN 试水（无需安装）

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<div id="app">{{ msg }}</div>
<script>
  Vue.createApp({
    data() { return { msg: 'Hello Vue 3' } }
  }).mount('#app')
</script>

方式二：构建工具（正式开发推荐）

npm create vite@latest my-vue-app -- --template vue
cd my-vue-app
npm install
npm run dev
方式 适用场景 优点 缺点
CDN 学语法、做 demo 零配置 无热更新、难工程化
Vite 真实项目 快、热更新、模块化 需 Node 环境

组合式 API 的最小骨架

<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">点了 {{ count }} 次</button>
</template>
script setup 是 Vue 3 推荐写法：顶层变量/函数自动暴露给模板，无需 return。

3.模板语法

语法 写法 说明
文本插值 {{ msg }} 双大括号，内容会被转义
原始 HTML v-html="raw" 渲染 HTML 字符串（慎用，有 XSS 风险）
属性绑定 :id="dynId" 或 v-bind:id 动态绑定属性
表达式 {{ count + 1 }} 支持 JS 表达式，不支持语句
插值里只能写单个表达式，不能写 if、for 等语句。

4.响应式核心：ref 与 reactive

这是 Vue 3 与 Vue 2 data() 最大的不同点。

API 适用类型 访问方式 示例
ref 基本类型 + 对象都行 .value 取值/赋值 const n = ref(0); n.value++
reactive 仅对象/数组 直接 .key const s = reactive({n:0}); s.n++ 
import { ref, reactive } from 'vue'

// 基本类型用 ref
const name = ref('Vue')
console.log(name.value) // 'Vue'
name.value = 'Vue 3'

// 对象用 reactive 更自然
const user = reactive({ age: 18 })
user.age++ // 18 -> 19
基本类型用 ref，对象数组 reactive； 实在分不清，全用 ref 也行（.value 别忘）。

解构陷阱：reactive 对象解构后会丢失响应式，要用 toRefs： 

const state = reactive({ x: 1, y: 2 })
const { x, y } = toRefs(state) // 保持响应式

5.计算属性 computed

基于响应式依赖缓存派生值。依赖不变就不重新计算。 

import { ref, computed } from 'vue'
const firstName = ref('张')
const lastName = ref('三')
const fullName = computed(() => firstName.value + lastName.value)
对比 computed methods
缓存 ✅ 依赖不变不重算 ❌ 每次调用都重算
写法 像属性 {{ fullName }} 像函数 {{ getFull() }}

可写计算属性（少见但有用）：

const fullName = computed({
  get: () => first.value + last.value,
  set: (v) => { [first.value, last.value] = v.split(' ') }
})

6.侦听器 watch / watchEffect

API 触发时机 需指定源 典型用途
watch 源变化时 ✅ 要指定监听谁 异步请求、特定副作用
watchEffect 立即执行 + 依赖变化时 ❌ 自动收集依赖 初始化即要跑的副作用 
import { ref, watch, watchEffect } from 'vue'
const count = ref(0)

// watch：明确监听 count
watch(count, (newVal, oldVal) => {
  console.log(`从 ${oldVal} 变到 ${newVal}`)
})

// watchEffect：自动追踪用到的响应式数据
watchEffect(() => {
  console.log('count 现在是', count.value)
})

watch 监听对象深层属性：加 { deep: true }；只监听某个字段用 getter： 

watch(() => user.age, (v) => {...})        // 精准
watch(user, (v) => {...}, { deep: true })  // 全量深层

7.类与样式绑定

动态 class（三种写法）

<!-- 对象：键为真则加类 -->
<div :class="{ active: isActive, 'text-red': hasError }"></div>
<!-- 数组：直接拼多个类 -->
<div :class="[activeClass, errorClass]"></div>
<!-- 数组里套对象 -->
<div :class="[{ active: isActive }, errorClass]"></div>

动态 style

<div :style="{ color: activeColor, fontSize: size + 'px' }"></div>
场景 推荐写法
单类开关 对象语法 :class="{on: flag}"
多类组合 数组语法 :class="[a, b]"

8.条件与列表渲染

指令 用途 说明
v-if / v-else-if / v-else 真正增删 DOM 切换开销大、运行时开销小
v-show display:none 切换 初始开销大、切换便宜
v-for 循环列表 必须带 :key 
<!-- 条件 -->
<p v-if="score >= 90">优秀</p>
<p v-else-if="score >= 60">及格</p>
<p v-else>不及格</p>

<!-- 列表 -->
<ul>
  <li v-for="(item, index) in list" :key="item.id">{{ index }} - {{ item.name }}</li>
</ul>
v-if 是删节点，v-show 是藏节点； 频繁切换用 show，一次性判断用 if。
v-for 与 v-if 不要同元素混用（Vue 3 中 v-if 优先级更高，逻辑混乱）。需要过滤时先 computed 过滤数组。

:key 是 Vue 复用节点的「身份证」，用稳定唯一值（如 id），不要用 index（增删时会错位出 bug）。

9.事件处理

<button @click="count++">加</button>
<button @click="say('hi', $event)">带参</button>
<button @click.stop="doThis">阻止冒泡</button>
<button @submit.prevent="onSubmit">阻止默认</button>
修饰符 作用
.stop event.stopPropagation() 阻止冒泡
.prevent event.preventDefault() 阻止默认行为
.once 只触发一次
.enter / .esc 按键修饰符（监听特定键）
冒泡用 .stop，默认用 .prevent； 想只一次 .once，按键写 .enter。

10.表单输入绑定

v-model = :value + @input 的语法糖。

表单元素 绑定结果
<input type="text"> 字符串
<input type="checkbox"> 单勾布尔 / 多勾数组
<input type="radio"> 选中的 value
<select> 选中项 value
<textarea> 字符串 
<input v-model="text" placeholder="输入"/>
<input type="checkbox" v-model="checked" /> {{ checked }}
<select v-model="city"><option value="bj">北京</option></select>

修饰符：.lazy（change 时更新）、.number（转数字）、.trim（去空格）。

第二篇：进阶篇（组件化）

组件是 Vue 的灵魂。把页面拆成「props 进、events 出」的独立积木。

11.组件基础与注册

<!-- Child.vue -->
<script setup>
defineProps({ title: String })
defineEmits(['change'])
</script>
<template><h2>{{ title }}</h2></template>
注册方式 写法 说明
局部注册 import Child from './Child.vue' 直接用 推荐，按需加载
全局注册 app.component('Child', Child) 全项目可用，慎用（体积/依赖不清）
局部优先全局，组件单一职责。

12.Props：父传子

<!-- 父 -->
<Child :user-name="name" :age="18" />
<!-- 子 -->
<script setup>
const props = defineProps({
  userName: { type: String, required: true },
  age: { type: Number, default: 0 }
})
console.log(props.userName)
</script>
要点 说明
单向数据流 子组件不能直接改 props（会报警告）
改名接收 defineProps 用 camelCase，模板用 kebab-case 传
对象/数组默认值 必须用工厂函数 default: () => ({})
想改父数据？让父传 @update 事件，或传 reactive 对象引用（改其属性，不推荐新手用）。

13.自定义事件 emits：子传父

<!-- 子 -->
<script setup>
const emit = defineEmits(['submit', 'update:modelValue'])
function onBtn() { emit('submit', { ok: true }) }
</script>
<template><button @click="onBtn">提交</button></template>

<!-- 父 -->
<Child @submit="handleSubmit" />

v-model 本质（组件上）：v-model:foo = :foo + @update:foo 

<Child v-model="text" />          <!-- 简写，对应 modelValue -->
<Child v-model:title="t" />       <!-- 具名 v-model -->

14.插槽 slots

插槽类型 用法 场景
默认插槽 <slot/> 父往子塞一段内容
具名插槽 <slot name="header"/> + <template #header> 多区域布局
作用域插槽 <slot :item="row"/> 子把数据回传给父，父决定渲染 
<!-- 子：Card.vue -->
<template>
  <div class="card">
    <slot name="header" />
    <slot :count="count" />   <!-- 作用域插槽 -->
  </div>
</template>

<!-- 父 -->
<Card>
  <template #header><h3>标题</h3></template>
  <template #default="{ count }"><p>当前 {{ count }}</p></template>
</Card>
默认塞内容，具名分区域； 作用域插槽，子把数据递。

15.生命周期钩子

钩子 时机 能做什么
onBeforeMount 挂载前 数据已就绪，DOM 还没
onMounted 挂载完成 ✅ 发请求、操作 DOM、初始化图表
onBeforeUpdate 更新前 拿到更新前状态
onUpdated 更新后 DOM 已刷新（少用）
onBeforeUnmount 卸载前 ✅ 清除定时器、解绑事件
onUnmounted 卸载后 清理收尾

组合式 API 中钩子以 onXxx 形式在 setup 内调用：

import { onMounted, onUnmounted } from 'vue'
onMounted(() => { /* 请求数据 */ })
对比 Vue 2：beforeCreate/created 在 setup 阶段已合并，无需再写。
挂载完再请求，卸载前清干净； mounted 取数据，unmounted 解绑定时。

16.依赖注入 provide / inject

跨多层组件传值，避免「props 逐层透传（prop drilling）」。

<!-- 祖先 -->
<script setup>
import { provide, ref } from 'vue'
const theme = ref('dark')
provide('theme', theme) // key, value
</script>

<!-- 任意后代 -->
<script setup>
import { inject } from 'vue'
const theme = inject('theme', 'light') // 第二个参数是默认值
</script>
项目 说明
优点 跨层传递，无需中间组件接力
缺点 耦合祖先与后代，破坏组件独立性
建议 仅用于「全局配置/主题」类数据，业务数据仍走 props/emit

17.组合式函数 composables

把可复用的状态逻辑抽成函数，文件名以 use 开头。这是 Vue 3 复用逻辑的终极方案（替代 Vue 2 的 mixin）。 

// composables/useCounter.js
import { ref } from 'vue'
export function useCounter() {
  const count = ref(0)
  const inc = () => count.value++
  return { count, inc }
}

// 组件中使用
<script setup>
import { useCounter } from './composables/useCounter'
const { count, inc } = useCounter()
</script>
对比 mixin 的优点：来源清晰、无命名冲突、可传参。

18.自定义指令

// 全局指令：v-focus
app.directive('focus', {
  mounted(el) { el.focus() }
})
<input v-focus />
钩子 作用
mounted 元素挂载后
updated 元素更新后
unmounted 卸载后
日常开发中自定义指令使用频率不高，记住「操作 DOM 的复用逻辑」才适合放指令即可。

19.过渡与动画

<Transition name="fade">
  <p v-if="show">我会淡入淡出</p>
</Transition>
.fade-enter-active, .fade-leave-active { transition: opacity .5s; }
.fade-enter-from, .fade-leave-to { opacity: 0; }
类名阶段 含义
*-enter-from 进入前状态
*-enter-active 进入过渡中
*-enter-to 进入后状态
*-leave-* 同理用于离开

列表用 <TransitionGroup>（需 key）。

第三篇：精通篇（工程化与原理）

20.Vue Router 路由

// router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '@/views/Home.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/user/:id', component: () => import('@/views/User.vue'), meta: { auth: true } }
]
const router = createRouter({ history: createWebHistory(), routes })
概念 说明
路由模式 createWebHistory（无 #）/ createWebHashHistory（带 #，部署简单）
动态路由 /user/:id，组件内用 useRoute().params.id 取
路由守卫 beforeEach 做登录鉴权等全局拦截
懒加载 () => import() 分包，首屏更快 
<script setup>
import { useRoute, useRouter } from 'vue-router'
const route = useRoute()   // 当前路由信息
const router = useRouter() // 跳转方法
router.push('/home')
</script>

21.Pinia 状态管理

Vue 官方推荐的状态库（取代 Vuex，更简洁）。

// stores/counter.js
import { defineStore } from 'pinia'
export const useCounterStore = defineStore('counter', {
  state: () => ({ count: 0 }),
  getters: { double: (s) => s.count * 2 },
  actions: { increment() { this.count++ } }
})

// 组件
<script setup>
import { useCounterStore } from '@/stores/counter'
const store = useCounterStore()
store.increment()
</script>

setup 风格（更贴合组合式）

export const useUserStore = defineStore('user', () => {
  const name = ref('')
  const setName = (v) => (name.value = v)
  return { name, setName }
})
对比 Pinia Vuex
写法 少样板代码 繁琐
TS 支持 原生友好 一般
mutation 取消，直接改 state 必须 commit
局部状态用 ref，跨组件共享才用 Pinia。

22.异步与网络请求

import { ref, onMounted } from 'vue'
const list = ref([])
const loading = ref(false)

async function fetchList() {
  loading.value = true
  try {
    const res = await fetch('/api/list')
    list.value = await res.json()
  } finally {
    loading.value = false
  }
}
onMounted(fetchList)
请求封装成 composables/useRequest.js 复用；或用 axios + 拦截器统一处理 token/错误。

25.响应式原理与虚拟 DOM

响应式原理（Proxy）

  • Vue 3 用 Proxy 代理对象，读取时收集依赖（track），修改时触发更新（trigger）。
  • 相比 Vue 2 的 Object.defineProperty：能监听新增/删除属性、数组索引变化，无需 $set。

虚拟 DOM 与 Diff

  • 数据变 → 生成新的虚拟 DOM（JS 对象描述） → 与旧 vnode Diff 比对 → 只把差异patch 到真实 DOM。
  • Diff 策略：同层比较，利用 key 复用节点，减少真实 DOM 操作（DOM 操作最慢）。
响应式靠 Proxy，读写拦截双兄弟； 虚拟 DOM 做比对，key 定复用差异 patch。

26.面试口诀与速查表

高频速查

问题 一句话答案
Vue 2 与 3 响应式区别 2 用 defineProperty（需 $set），3 用 Proxy
computed vs watch 要返回值用 computed，要副作用用 watch
v-if vs v-show 删节点 vs 隐藏
为什么 v-for 要 key 稳定标识，精准复用，避免错位
组件通信方式 props/emit、provide/inject、Pinia、事件总线(少用)
ref vs reactive 基本类型 ref，对象 reactive
路由守卫用途 登录鉴权、页面权限
状态管理选型 跨组件共享用 Pinia，局部用 ref
数据驱动响应式，组件通信 props/emit； 计算缓存侦听副作用，生命周期挂载卸载清； 路由 Pinia 工程化，Proxy 虚拟 DOM 是底层； 入门打基础，进阶拆组件，精通读原理。
