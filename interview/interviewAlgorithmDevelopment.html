01复杂度与算法基础

Q
大 O 时间复杂度是什么？怎么估算？🔥 高频

定义：描述运行时间随输入规模 n 增长的趋势上界，与机器无关，忽略常数和低阶项。

  • 加法规则：顺序执行的代码取最大项，O(n²) + O(n) = O(n²)
  • 乘法规则：嵌套执行相乘，两层循环各 n 次即 O(n²)
  • 估算方法：数最深层循环的执行次数；递归看「调用次数 × 单次开销」
「常数忽略、低阶砍掉、只留最大项」；先数嵌套层数猜量级，再看每层干多少活
Q
常见时间复杂度从小到大排列？各对应什么典型算法？
复杂度 名称 典型算法 n = 10⁵ 时的耗时级别
O(1) 常数 哈希查找、数组下标访问 瞬间
O(log n) 对数 二分查找、快速幂、堆操作 约 17 次操作
O(n) 线性 遍历数组、双指针、计数 可过
O(n log n) 线性对数 归并 / 快排 / 堆排、排序后二分 可过（上限）
O(n²) 平方 双层循环、朴素 DP、冒泡插入 超时
O(2ⁿ) 指数 子集枚举、朴素斐波那契 n > 30 就爆炸
O(n!) 阶乘 全排列枚举 n > 12 就爆炸
口诀「常对线、方指阶」——常数、对数、线性、线性对数、平方、指数、阶乘；面试口算量级必备
Q
递归的时间复杂度怎么分析？🔥 高频

核心公式：总时间 = 递归调用总次数 × 每次操作时间。

  • 二分查找：T(n) = T(n/2) + O(1) → 每次problems 减半、单次常数 → O(log n)
  • 归并排序：T(n) = 2T(n/2) + O(n) → log n 层、每层合并 O(n) → O(n log n)
  • 朴素斐波那契：T(n) = T(n-1) + T(n-2) → 递归树近似二叉树 → O(2ⁿ)
  • 通用技巧：画递归树，数总节点数（调用次数），每节点成本就是答案

主定理（加分项）：T(n) = aT(n/b) + f(n)，比较 f(n) 与 n^(log_b a) 的大小取较大者。

「次数乘单耗」；砍半 logn、分半合并 nlogn、双分支自己调自己指数炸
Q
空间复杂度算什么？
  • 只算额外开辟的辅助空间，不算输入本身
  • 递归调用栈要计入：递归深度多少层，就至少 O(深度)
  • 原地算法 O(1)：双指针交换、原地反转、快排（忽略栈 log n）
  • 归并排序需要 O(n) 辅助数组，所以「内存敏感选快排」
「额外空间才算数，递归栈深要计入；原地算法就是 O(1)」

算法题面试的标准答题流程是什么？🔥 高频
  1. 确认题意：输入输出是什么？空输入、负数、重复值？数据范围多大？
  2. 举例模拟：自己造一个小用例，手推一遍验证理解
  3. 说出思路与复杂度：先给暴力解，再优化；让面试官确认后再写码
  4. 边写边讲：写码时同步说思路，不要沉默
  5. 主动测试：写完拿用例逐行走一遍，检查边界
「先问清、再举例、报思路、再动手、写完测」；面试考的是沟通过程，不是默写答案
Q
写完代码如何自测？
  • 三类用例：正常值、边界值（空 / 单元素 / 极大极小）、特殊值（重复 / 全相同 / 已排序 / 负数）
  • 重点检查循环边界：i 从 0 还是 1 开始、< 还是 <=、会不会越界
  • 检查不变量：如「循环里 left 左边永远 < target」，写码时心里维护
「正常、边界、特殊三件套」；大多数 bug 死在等号和空输入上
Q
拿到题没思路怎么办？有什么通用思维？
  • 按数据特征套模板：数组→双指针/滑窗/前缀和；字符串→滑窗/哈希；有序→二分；求所有解→回溯；求最值→DP/贪心；连通性→并查集/搜索
  • 数据范围反推复杂度：n ≤ 20 可以指数回溯；n ≤ 5000 可 O(n²)；10⁵ 以上必须 O(n log n) 或 O(n)
  • 先暴力再优化：暴力解能拿分，也常是优化的起点（暴力里找重复计算）
  • 变小变大：n=1、n=2 手推规律；或从最后一步倒推（DP 思维）
「范围定复杂度，特征对套路；实在不行先暴力」

Q
双指针有哪几类？分别解决什么问题？🔥 高频

  • 快慢指针（同向不同速）：原地删除 / 去重、移除元素、链表环检测
  • 滑动窗口（同向、维护区间）：最长 / 最短子数组、字符串子串问题

「对撞夹中间，快慢清原地，窗口管区间」；有序数组几乎必先想对撞
Q
两数之和（LeetCode 1）🔥 高频

思路：一遍哈希。遍历时先查「target − 当前值」是否出现过，出现过直接返回；没出现就把「当前值 → 下标」存进哈希表。

时间 O(n)，空间 O(n)。暴力双循环 O(n²) 是对照组，面试先说再优化。 

                
                def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}                        # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen:       # 伴侣先到了吗？
            return [seen[target - x], i]
        seen[x] = i
    return []
              
                
                function twoSum(nums: number[], target: number): number[] {
    const seen = new Map<number, number>();  // 值 -> 下标
    for (let i = 0; i < nums.length; i++) {
        const need = target - nums[i];
        if (seen.has(need)) return [seen.get(need)!, i];
        seen.set(nums[i], i);
    }
    return [];
}
「一边走一边问：我的另一半来了吗？没来就登记自己」；Map 取值三件套 has / get / !
Q
三数之和（LeetCode 15）🔥 高频

思路：排序 + 固定一个数 + 对撞双指针。时间 O(n²)。难点全在去重：

  • 固定的 i：跳过 nums[i] == nums[i-1]
  • 命中后：left、right 各自跳过相同值再收缩
                
                def three_sum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    res, n = [], len(nums)
    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:     # 去重 i
            continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]: l += 1  # 去重 l
                while l < r and nums[r] == nums[r - 1]: r -= 1  # 去重 r
                l += 1; r -= 1
    return res
              
                
                function threeSum(nums: number[]): number[][] {
    nums.sort((a, b) => a - b);
    const res: number[][] = [];
    const n = nums.length;
    for (let i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] === nums[i - 1]) continue;  // 去重 i
        let l = i + 1, r = n - 1;
        while (l < r) {
            const s = nums[i] + nums[l] + nums[r];
            if (s < 0) l++;
            else if (s > 0) r--;
            else {
                res.push([nums[i], nums[l], nums[r]]);
                while (l < r && nums[l] === nums[l + 1]) l++;  // 去重 l
                while (l < r && nums[r] === nums[r - 1]) r--;  // 去重 r
                l++; r--;
            }
        }
    }
    return res;
}
「排序定 i，左右夹击，和小动左、和大动右」；去重口诀「跳过与前一个相同」
Q
盛最多水的容器（LeetCode 11）🔥 高频

思路：对撞指针从两端开始，面积 = min(左高, 右高) × 宽度。每次移动矮的那端——移动高的那端，高度上限不变、宽度还变小，面积不可能变大。

时间 O(n)，空间 O(1)。

「谁矮谁动」；木桶效应：面积由短板决定，换掉短板才有机会变大

合并两个有序数组（LeetCode 88）

思路：nums1 尾部有空位，从后往前三指针合并（i、j 指有效尾部，k 指最终尾部），每次放较大的，避免从前往后覆盖未处理的元素。

Q
旋转数组 k 步（LeetCode 189）？

思路：三次翻转法。k 先对 n 取模；①整体翻转 ②翻转前 k 个 ③翻转后 n−k 个。时间 O(n)、空间 O(1)。

例如 [1,2,3,4,5,6,7] 旋转 3 步：整体翻 → [7,6,5,4,3,2,1] → 前 3 翻 [5,6,7] + 后 4 翻 [1,2,3,4]。

「整体翻 + 前后翻」，原地完成不用辅助数组
Q
缺失的第一个正数（LeetCode 41）？🔥 高频

题意：O(n) 时间、O(1) 空间找未出现的最小正整数（Hard 里必背的套路题）。

思路：原地哈希——把值 v（1 ≤ v ≤ n）通过 swap 归位到下标 v−1；全部归位后，第一个 nums[i] != i + 1 的位置，答案就是 i+1；全都满足则答案是 n+1。

「值 x 回家去 x−1，第一个不在家的位置就是答案」；原地哈希 = 拿数组当下标用
Q
数组去重的几种写法？
  • 无序数组：哈希集合。Python list(set(nums))；TS [...new Set(nums)]（注意会变序）
  • 有序数组原地去重（LeetCode 26）：快慢指针，slow 指向已保留区末尾，fast 找新值
  • 保序去重：遍历 + seen 集合，没见过才写入结果
「有序双指针，无序上 set；要保序就边走边记」
Q
数组题的整体套路总结？
  • 区间和 → 前缀和；连续子数组 → 滑动窗口
  • 原地操作 → 双指针交换（O(1) 空间）
  • 有重复 / 找组合 → 先排序（排序只花 n log n，常常白送）
  • 下标即信息 → 原地哈希（缺失数字、找重复数）
「和用前缀，区间用滑窗，原地靠交换，重复先排序」

03字符串与滑动窗口

Q
滑动窗口的通用套路是什么？🔥 高频

适用：求连续子串 / 子数组的「最长、最短、满足某条件」问题。

  1. right 逐步右移，把新元素纳入窗口并更新状态（计数、和……）
  2. 当窗口不满足条件时，while 收缩 left，边缩边撤销状态
  3. 窗口合法时更新答案（最长取扩张后，最短取收缩后）

本质：左右指针都只前进不后退，每个元素最多进出窗口各一次，O(n)。

「右进左缩，进改状态，缩复原状」；两指针都不回头，复杂度必然 O(n)
Q
最长无重复字符的子串（LeetCode 3）🔥 高频

思路：滑窗 + 哈希记录每个字符最后出现的下标。遇到重复字符时，left 直接跳到「重复字符上次位置 + 1」（注意 left 只前进不后退）。时间 O(n)。 

                
                def length_of_longest_substring(s: str) -> int:
    last = {}                     # 字符 -> 最后出现的下标
    left = ans = 0
    for r, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1    # 左边界直接跳过重复字符
        last[ch] = r
        ans = max(ans, r - left + 1)
    return ans
              
                
                function lengthOfLongestSubstring(s: string): number {
    const last = new Map<string, number>();  // 字符 -> 最后下标
    let left = 0, ans = 0;
    for (let r = 0; r < s.length; r++) {
        const ch = s[r];
        if (last.has(ch) && last.get(ch)! >= left) {
            left = last.get(ch)! + 1;        // 跳过重复字符
        }
        last.set(ch, r);
        ans = Math.max(ans, r - left + 1);
    }
    return ans;
}
「记位置，跳重复，取最大窗口」；left 只能往右走，别被回头写法坑了
Q
最长回文子串（LeetCode 5）🔥 高频

思路：中心扩展法。回文中心有 2n−1 个（n 个单字符中心 + n−1 个字符间隙中心），对每个中心向两边扩到不能扩为止，记录最长。时间 O(n²)、空间 O(1)。

加分项：Manacher 算法 O(n)，面试一般只需说出名字与思想（插入 # 统一奇偶 + 利用已知回文的对称性）。 

                
                def longest_palindrome(s: str) -> str:
    start = end = 0

    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return l + 1, r - 1              # 回到合法位置

    for i in range(len(s)):
        for l, r in (expand(i, i), expand(i, i + 1)):   # 奇偶两种中心
            if r - l > end - start:
                start, end = l, r
    return s[start:end + 1]
              
                
                function longestPalindrome(s: string): string {
    let start = 0, end = 0;
    const expand = (l: number, r: number): [number, number] => {
        while (l >= 0 && r < s.length && s[l] === s[r]) {
            l--; r++;
        }
        return [l + 1, r - 1];            // 回到合法位置
    };
    for (let i = 0; i < s.length; i++) {
        for (const [l, r] of [expand(i, i), expand(i, i + 1)]) { // 奇偶中心
            if (r - l > end - start) { start = l; end = r; }
        }
    }
    return s.slice(start, end + 1);
}
「一个字符一个缝，共 2n−1 个中心往外撑」；奇偶中心都要试

        nxt = cur.next      # 1. 先存后继
        cur.next = prev     # 2. 掉头反指
        prev, cur = cur, nxt  # 3. 双双右移

判断链表有环？环的入口在哪？（LeetCode 141 / 142）🔥 高频

判环：快慢指针，fast 每次两步、slow 每次一步，相遇则有环（fast 先到 None 则无环）。

找入口：相遇后，一个指针回到 head，两指针同速前进，再次相遇的位置就是环入口。推导：设头到入口 a、入口到相遇点 c、环长 L，相遇时 slow 走了 a+c，fast 走了 a+c+kL 且是两倍 → a+c = kL → a = (k−1)L + (L−c)，即从头走到入口的步数恰好等于从相遇点绕 (k−1) 圈到入口的步数。 

                
                def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:                 # 相遇：有环
            p = head
            while p is not slow:         # 一个回头，同速再走
                p, slow = p.next, slow.next
            return p                     # 再相遇 = 环入口
    return None
              
                
                function detectCycle(head: ListNode | null): ListNode | null {
    let slow = head, fast = head;
    while (fast && fast.next) {
        slow = slow!.next;
        fast = fast.next.next;
        if (slow === fast) {             // 相遇：有环
            let p = head;
            while (p !== slow) {         // 一个回头，同速再走
                p = p!.next;
                slow = slow!.next;
            }
            return p;                    // 再相遇 = 环入口
        }
    }
    return null;
}

LRU 缓存机制（LeetCode 146）🔥 高频

要求：get / put 都 O(1)。数据结构 = 哈希表 + 双向链表：哈希定位节点 O(1)，双向链表摘除 / 头插 O(1)；新访问的放头部，满了删尾部。

语言捷径：Python 用 OrderedDict（move_to_end + popitem）；TS 用 Map——它本身按插入序遍历，get 后 delete+set 即可移到末尾，首个 key 就是最久未用的。 

                
                from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.od = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.od:
            return -1
        self.od.move_to_end(key)       # 提到尾部 = 最近使用
        return self.od[key]

    def put(self, key: int, value: int) -> None:
        if key in self.od:
            self.od.move_to_end(key)
        self.od[key] = value
        if len(self.od) > self.cap:
            self.od.popitem(last=False)  # 弹出头部 = 最久未用
              
                
                class LRUCache {
    private cap: number;
    private map = new Map<number, number>();

    constructor(capacity: number) { this.cap = capacity; }

    get(key: number): number {
        if (!this.map.has(key)) return -1;
        const val = this.map.get(key)!;
        this.map.delete(key);           // 删了重插 = 移到末尾
        this.map.set(key, val);
        return val;
    }

    put(key: number, value: number): void {
        if (this.map.has(key)) this.map.delete(key);
        this.map.set(key, value);
        if (this.map.size > this.cap) {
            const oldest = this.map.keys().next().value;  // 首个 key 最久未用
            this.map.delete(oldest!);
        }
    }
}

    pair = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pair:                          # 右括号：弹栈匹配
            if not stack or stack.pop() != pair[ch]:

        else:

        if (ch in pair) {                       // 右括号：弹栈匹配
            if (stack.pop() !== pair[ch]) return false;
        } else {
            stack.push(ch);                     // 左括号：入栈
        }
    }
    return stack.length === 0;                  // 栈空才有效
}

    ans = [0] * len(T)
    stack = []                                 # 存「还没等到升温」的下标
    for i, t in enumerate(T):
        while stack and T[stack[-1]] < t:      # 栈顶等到了
            j = stack.pop()
            ans[j] = i - j
        stack.append(i)
    return ans                                 # 没等到的一直是 0

                def subarray_sum(nums: list[int], k: int) -> int:
    count = {0: 1}              # 前缀和 0 出现一次（空前缀）
    pre = ans = 0
    for x in nums:
        pre += x
        ans += count.get(pre - k, 0)     # 多少个旧前缀和 = pre-k
        count[pre] = count.get(pre, 0) + 1
    return ans
              
                
                function subarraySum(nums: number[], k: number): number {
    const count = new Map<number, number>([[0, 1]]);  // 空前缀
    let pre = 0, ans = 0;
    for (const x of nums) {
        pre += x;
        ans += count.get(pre - k) ?? 0;   // 多少个旧前缀和 = pre-k
        count.set(pre, (count.get(pre) ?? 0) + 1);
    }
    return ans;
}

                from collections import deque

def level_order(root):
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):       # 当前层节点数
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res

function levelOrder(root: TreeNode | null): number[][] {
    if (!root) return [];
    const res: number[][] = [];
    const queue: TreeNode[] = [root];
    while (queue.length) {
        const level: number[] = [];

            level.push(node.val);
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        res.push(level);
    }
    return res;
}

                def permute(nums: list[int]) -> list[list[int]]:
    res, path, used = [], [], [False] * len(nums)

    def backtrack():
        if len(path) == len(nums):     # 结束条件
            res.append(path[:])        # 必须拷贝！
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True             # 做选择
            path.append(nums[i])
            backtrack()
            path.pop()                 # 撤销选择
            used[i] = False

    backtrack()
    return res
              
                
                function permute(nums: number[]): number[][] {
    const res: number[][] = [];
    const path: number[] = [];
    const used = new Array<boolean>(nums.length).fill(false);

    const backtrack = (): void => {
        if (path.length === nums.length) {   // 结束条件
            res.push([...path]);             // 必须拷贝！
            return;
        }
        for (let i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;                  // 做选择
            path.push(nums[i]);
            backtrack();
            path.pop();                      // 撤销选择
            used[i] = false;
        }
    };
    backtrack();
    return res;
}

标准二分模板与易错点？🔥 高频

模板（闭区间 [l, r]）：`while l <= r`，mid 防溢出写法，命中返回，否则收缩半边。

  • 易错一：l <= r 还是 l < r 取决于区间开闭约定，写法要配套
  • 易错二：left = mid 时可能死循环，mid 要取上中位或收缩方向配 +1/−1
  • 易错三：找左 / 右边界时命中不返回，继续往边界压
  • JS 位运算 (l + r) >> 1 是 32 位有符号，超大数组用 Math.floor((l + r) / 2) 更稳 
                
                def binary_search(nums: list[int], target: int) -> int:
    l, r = 0, len(nums) - 1            # 闭区间 [l, r]
    while l <= r:
        mid = l + (r - l) // 2         # 防溢出写法
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            l = mid + 1                # 收缩左半
        else:
            r = mid - 1                # 收缩右半
    return -1
              
                
                function binarySearch(nums: number[], target: number): number {
    let l = 0, r = nums.length - 1;       // 闭区间 [l, r]
    while (l <= r) {
        const mid = l + Math.floor((r - l) / 2);  // 防溢出写法
        if (nums[mid] === target) return mid;
        if (nums[mid] < target) l = mid + 1;       // 收缩左半
        else r = mid - 1;                          // 收缩右半
    }
    return -1;
}

}

                import random

def quick_sort(nums, l, r):
    if l >= r:
        return
    p = partition(nums, l, r)
    quick_sort(nums, l, p - 1)
    quick_sort(nums, p + 1, r)

def partition(nums, l, r):
    rand = random.randint(l, r)        # 随机基准防退化
    nums[rand], nums[r] = nums[r], nums[rand]
    pivot = nums[r]
    i = l - 1                          # i 是「小于区」右边界
    for j in range(l, r):
        if nums[j] <= pivot:
            i += 1
            nums[i], nums[j] = nums[j], nums[i]
    nums[i + 1], nums[r] = nums[r], nums[i + 1]
    return i + 1                       # 基准的最终位置
              
                
                function quickSort(nums: number[], l = 0, r = nums.length - 1): number[] {
    if (l >= r) return nums;
    const p = partition(nums, l, r);
    quickSort(nums, l, p - 1);
    quickSort(nums, p + 1, r);
    return nums;
}

function partition(nums: number[], l: number, r: number): number {
    const rand = l + Math.floor(Math.random() * (r - l + 1)); // 随机基准
    [nums[rand], nums[r]] = [nums[r], nums[rand]];
    const pivot = nums[r];
    let i = l - 1;                       // i 是「小于区」右边界
    for (let j = l; j < r; j++) {
        if (nums[j] <= pivot) {
            i++;
            [nums[i], nums[j]] = [nums[j], nums[i]];
        }
    }
    [nums[i + 1], nums[r]] = [nums[r], nums[i + 1]];
    return i + 1;                        // 基准的最终位置
}

TopK 问题：找最大的 k 个数？🔥 高频

方法一（最标准）：维护一个大小为 k 的小顶堆——新元素比堆顶大就替换。堆里始终是「目前见过的最大 k 个」，堆顶是它们中最小的（守门员）。O(n log k)，特别适合海量数据 / 流式数据。

方法二：快排思想 QuickSelect——partition 后若基准恰好在第 k 位即答案，只递归一侧，平均 O(n)，但需要数据全在内存且会改动原数组。

                import heapq

def top_k(nums: list[int], k: int) -> list[int]:
    heap = nums[:k]                     # 前 k 个建小顶堆
    heapq.heapify(heap)
    for x in nums[k:]:
        if x > heap[0]:                 # 比守门员强才上场
            heapq.heapreplace(heap, x)
    return sorted(heap, reverse=True)   # 堆里就是最大的 k 个
              
                
                class MinHeap {                        // JS 无内置堆，手写一个小顶堆
    private a: number[] = [];
    get size() { return this.a.length; }
    top() { return this.a[0]; }

    push(x: number): void {
        this.a.push(x);
        let i = this.a.length - 1;
        while (i > 0) {                                  // 上浮
            const p = (i - 1) >> 1;
            if (this.a[p] <= this.a[i]) break;
            [this.a[p], this.a[i]] = [this.a[i], this.a[p]];
            i = p;
        }
    }

    pop(): number {
        const top = this.a[0], last = this.a.pop()!;
        if (this.a.length) {
            this.a[0] = last;
            let i = 0;                                   // 下沉
            while (true) {
                const l = i * 2 + 1, r = i * 2 + 2;
                let m = i;
                if (l < this.a.length && this.a[l] < this.a[m]) m = l;
                if (r < this.a.length && this.a[r] < this.a[m]) m = r;
                if (m === i) break;
                [this.a[i], this.a[m]] = [this.a[m], this.a[i]];
                i = m;
            }
        }
        return top;
    }

    values(): number[] { return [...this.a]; }
}

function topK(nums: number[], k: number): number[] {
    const heap = new MinHeap();
    for (const x of nums) {
        if (heap.size < k) heap.push(x);
        else if (x > heap.top()) { heap.pop(); heap.push(x); }  // 换守门员
    }
    return heap.values().sort((a, b) => b - a);
}

                def knapsack(weights, values, cap):
    dp = [0] * (cap + 1)              # dp[j] = 容量 j 的最大价值
    for i in range(len(weights)):     # 每件物品只能选一次
        for j in range(cap, weights[i] - 1, -1):   # 倒序！
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[cap]
              
                
                function knapsack(weights: number[], values: number[], cap: number): number {
    const dp = new Array<number>(cap + 1).fill(0);
    for (let i = 0; i < weights.length; i++) {      // 每件只能选一次
        for (let j = cap; j >= weights[i]; j--) {   // 倒序！
            dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[cap];
}

                function coinChange(coins: number[], amount: number): number {
    const dp = new Array<number>(amount + 1).fill(Infinity);
    dp[0] = 0;
    for (const coin of coins) {                       // 物品外层

            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }

}

最长递增子序列 LIS（LeetCode 300）🔥 高频

O(n²) DP：dp[i] = 以 nums[i] 结尾的 LIS 长度 = max(dp[j] + 1)，j < i 且 nums[j] < nums[i]。

O(n log n) 贪心 + 二分：维护 tails 数组，tails[k] = 长度为 k+1 的递增子序列的最小可能结尾。新元素：找到第一个 ≥ 它的位置替换（让结尾更小、未来更容易接）；比全部都大就追加（LIS 变长）。tails 的长度即 LIS 长度（tails 本身不一定是 LIS）。 

                
                import bisect

def length_of_lis(nums: list[int]) -> int:
    tails = []                    # tails[k] = 长度 k+1 的 LIS 的最小结尾
    for x in nums:
        pos = bisect.bisect_left(tails, x)
        if pos == len(tails):
            tails.append(x)       # 比谁都大 -> LIS 变长
        else:
            tails[pos] = x        # 替换，让结尾更小更贪心
    return len(tails)
              
                
                function lengthOfLIS(nums: number[]): number {
    const tails: number[] = [];           // 长度 k+1 的 LIS 的最小结尾
    for (const x of nums) {
        let l = 0, r = tails.length;
        while (l < r) {                   // 手写二分找第一个 >= x 的位置
            const m = (l + r) >> 1;
            if (tails[m] < x) l = m + 1;
            else r = m;
        }
        if (l === tails.length) tails.push(x);  // 比谁都大 -> LIS 变长
        else tails[l] = x;                      // 替换，让结尾更小
    }
    return tails.length;
}

                function merge(intervals: number[][]): number[][] {
    intervals.sort((a, b) => a[0] - b[0]);     // 按左端点排序
    const res: number[][] = [];
    for (const [s, e] of intervals) {
        const last = res[res.length - 1];
        if (res.length && s <= last[1]) {      // 与上一区间重叠
            last[1] = Math.max(last[1], e);    // 右端取大
        } else {
            res.push([s, e]);                  // 开新区间
        }
    }
    return res;
}

                import random

def shuffle(nums: list[int]) -> list[int]:
    for i in range(len(nums) - 1, 0, -1):   # 从最后一张往前
        j = random.randint(0, i)            # 只和前面的位置换
        nums[i], nums[j] = nums[j], nums[i]
    return nums
              
                
                function shuffle(nums: number[]): number[] {
    for (let i = nums.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1)); // [0, i] 内随机
        [nums[i], nums[j]] = [nums[j], nums[i]];
    }
    return nums;
}
「从后往前，随手一换，人人平等」；水塘抽样是它的流式版亲戚

  1. 第一阶段按专题刷：数组 → 链表 → 栈队列 → 二叉树 → 图 → 二分 → DP，每个专题吃透 15~20 题经典题

面试遇到完全没见过的题怎么办？
  1. 读题三遍：确认每个名词、每个条件（很多「难题」只是题意陷阱）
  2. 造最小例子：n=1、n=2 手推，观察规律
  3. 先说暴力：哪怕是 O(n²)，先拿住基本分，再从暴力的重复计算处找优化点
  4. 对特征：有序→二分；连通→搜索/并查集；求所有解→回溯；求最值→DP/贪心
  5. 看数据范围：n ≤ 20 枚举/状压也可以过，别死磕最优解
  6. 卡住就说出思考过程——面试官的提示就是考察能力的机会
「读懂、举小、暴力、对特征、看范围」；展示思路过程比憋出完美答案更重要

海量数据处理题的套路？🔥 高频

核心思想：内存装不下 → 哈希分片把大问题拆成小问题，逐个解决再归并。

  • TopK（10GB 日志找访问最多的 10 个 IP）：hash(IP) % 100 分到 100 个小文件（同一 IP 必进同一文件）→ 每个文件内哈希计数 + 小顶堆取 Top10 → 100 组 Top10 归并出全局 Top10
  • 判存在 / 去重（100 亿 URL）：布隆过滤器（省内存）或哈希分片后每片 set 去重
  • 统计出现次数：位图（值域是整数时，bit 数组计数）
  • 两个大文件求交集：分片后小文件两两配对求交
「大化小（哈希分片），小求全（堆 / 位图 / 布隆），再归并」；分片用 hash 保证同 key 落同片是关键

怎么用数据范围反推需要的复杂度？🔥 高频

经验法则（按 1 秒约 10⁸ 次基本操作估算）：

n 的范围 可接受复杂度 对应算法方向
n ≤ 20 O(2ⁿ) 回溯、状压枚举、 bitmask
n ≤ 500 O(n³) 三重循环、区间 DP
n ≤ 5000 O(n²) 朴素 DP、双层循环
n ≤ 10⁵ ~ 10⁶ O(n log n) / O(n) 排序、二分、堆、滑窗、单调栈
n ≥ 10⁹ O(log n) / O(1) 数学、快速幂、二分答案
