01 数学与图像基础

Q
图像在计算机中是如何表示的？🔥 高频

图像本质是一个多维数组（张量）：

  • 灰度图：H × W 的二维矩阵，每个像素是 0~255 的亮度值
  • 彩色图：H × W × 3 的三维张量，3 个通道（RGB/BGR）
  • 位深：8bit = 256 级；医疗影像常用 16bit
  • 像素值含义：光强量化值，取值范围 [0, 255]

深度学习框架中常用 (B, C, H, W) 四维张量批量表示图像（PyTorch），OpenCV/NumPy 用 (H, W, C)。

图即矩阵：灰度是 2 维、彩图是 3 维、带 batch 是 4 维
Q
为什么要做图像归一化？BGR 和 RGB 有什么坑？🔥 高频

归一化原因：

  • 让输入分布稳定，加快收敛、避免梯度病态
  • 常用方式：除以 255 缩放到 [0,1]，或减均值除方差（如 ImageNet 的 mean/std）
  • 必须与训练时的预处理完全一致，否则精度大幅下降

BGR/RGB 的坑：OpenCV 默认读取为 BGR，PIL/matplotlib 默认 RGB。混用会导致输入通道顺序错误，精度莫名下降。

部署翻车重灾区：训练用 PIL+RGB，部署用 OpenCV+BGR，通道顺序没换，模型直接"失明"。
归一化保一致，通道顺序要对齐；CV 读图是 BGR，换框架先转 RGB
Q
图像缩放有哪些插值方法？各有什么特点？🔥 高频
方法 原理 特点
最近邻 取最近像素值 最快，有锯齿、块状
双线性 相邻 4 像素加权 速度/质量均衡，最常用
双三次 相邻 16 像素加权 更平滑，较慢
Lanczos sinc 核加窗 质量最高，保留细节
  • 缩小：注意走样，先高斯模糊再下采样
  • 放大：插值补信息；超分辨率可用 learned 模型
  • 区域插值（INTER_AREA）适合缩小，抗摩尔纹
最近邻快而糙，双线性是万金油，缩小用 AREA，放大用 LANCZOS
Q
直方图均衡化的原理是什么？

思想：把像素灰度的分布拉平，让直方图均匀覆盖 [0,255]，提升对比度。

  • 统计灰度直方图 → 求累积分布函数（CDF）→ 用 CDF 作为映射函数重映射像素
  • 效果：暗部细节被"拉开"，整体对比度增强
  • 缺点：全局变换，可能过度增强背景噪声
  • 改进：自适应直方图均衡（CLAHE）——分块做均衡再限制对比度放大倍数，适合光照不均场景
CDF 当映射，直方图拉平；怕过头就用 CLAHE 分块限幅
Q
什么是卷积？输出尺寸怎么算？🔥 高频

卷积：卷积核在图像上滑动，对应位置相乘再求和，提取局部特征（边缘、纹理、角点等）。

输出尺寸公式（必背）：

O = floor((I + 2P - K) / S) + 1

I = 输入尺寸  K = 卷积核尺寸
P = padding   S = 步长

例：输入 224、核 3、padding 1、步长 1 → 输出 224（尺寸不变，VGG 风格）。

输入加两倍补，减去核大小，除以步长取整，最后加个一
Q
什么是感受野？如何计算？🔥 高频

定义：特征图上一个点对应输入图像上的区域大小，即"这个神经元能看到多大范围的原图"。

  • 逐层计算：rl = rl-1 + (kl - 1) × jl-1，其中 j 是跳跃间距（之前所有步长的连乘）
  • 堆叠两层 3×3 卷积 = 一层 5×5 的感受野，但参数更少（18 vs 25）、非线性更强 → VGG 的设计哲学
  • 下采样（池化/步长2）指数级扩大感受野
  • 感受野不足 → 只能看到局部，语义不完整；太大 → 浪费算力
小核堆叠换大感受野：两个 3×3 顶一个 5×5，三个顶一个 7×7
Q
常见颜色空间有哪些？各自的应用场景？
颜色空间 构成 典型用途
RGB 红绿蓝三通道 显示器、通用图像表示
HSV 色调/饱和度/明度 颜色分割、目标追踪（光照鲁棒）
Lab 亮度 + a/b 色度 色彩迁移、感知均匀的距离计算
YUV/YCrCb 亮度 + 色度 视频压缩（人眼对亮度敏感）
灰度 单通道亮度 边缘检测、传统算法

关键点：HSV 把"是什么颜色"（H）和"多亮"（V）解耦，所以基于颜色的分割（如红色交通灯检测）常用 HSV 阈值。

分割颜色用 HSV，视频压缩用 YUV，算距离用 Lab
Q
讲一下相机成像模型？内参和外参是什么？🔥 高频

针孔相机模型（必背公式）：

s · [u, v, 1]ᵀ = K · [R | t] · [X, Y, Z, 1]ᵀ

K = [fx  0  cx]        fx, fy: 焦距(像素单位)
    [0   fy cy]        cx, cy: 光心(图像中心偏移)
    [0   0   1]        K 即"内参"矩阵
  • 内参 K：相机自身属性（焦距、光心、畸变系数），标定一次长期有效
  • 外参 [R|t]：相机相对世界坐标系的旋转和平移，随位姿变化
  • 标定方法：张正友标定法——拍多张棋盘格，解 K 和畸变
  • 单目无法直接测深度，需要双目视差或结构光/ToF
内参管相机（焦距光心），外参管姿态（旋转平移）；棋盘格一摆，张正友标定
Q
图像畸变有哪些类型？怎么矫正？
  • 径向畸变：透镜形状引起，直线变弯
    • 枕形畸变（放大向外弯）、桶形畸变（缩小向内弯）
  • 切向畸变：透镜与成像平面不平行（装配误差）引起，图像轻微倾斜拉伸
  • 矫正：用畸变系数（k1, k2, k3 径向 + p1, p2 切向）对像素坐标做多项式重映射，再插值取值
  • OpenCV：cv2.undistort(img, K, dist_coeffs)，畸变系数来自标定
径向弯（桶形/枕形），切向斜；五个系数一重映射就直了

02 传统图像处理与特征

Q
常见的边缘检测算子有哪些？🔥 高频
算子 类型 特点
Sobel 一阶导数 3×3，分 X/Y 方向，抗噪一般
Prewitt 一阶导数 类似 Sobel，核内权重平均
Laplacian 二阶导数 各向同性，对噪声敏感，常先高斯平滑（LoG）
Canny 多阶段 效果最好、最常用，边缘细且连续

本质：边缘 = 灰度突变处 → 一阶导数取极值，二阶导数过零点。

一阶求极值，二阶看过零；Sobel 求方向，Canny 是王者
Q
Canny 边缘检测的完整流程？🔥 高频
  1. 高斯平滑：降噪，减少噪声引起的伪边缘
  2. 计算梯度：Sobel 求 X/Y 方向梯度幅值和方向
  3. 非极大值抑制（NMS）：沿梯度方向只保留局部最大值，把粗边缘变细
  4. 双阈值检测：高于高阈值为强边缘，低于低阈值舍弃，之间为弱边缘
  5. 滞后连接：弱边缘只有与强边缘连通才保留，抑制孤立噪声
高斯去噪 → 梯度找边 → NMS 变细 → 双阈值分级 → 连接定生死
Q
高斯滤波、均值滤波、中值滤波的区别？
  • 均值滤波：邻域取平均 → 简单但模糊严重，对椒盐噪声无效
  • 高斯滤波：邻域加权平均（中心权重大）→ 平滑自然，抑制高斯噪声
  • 中值滤波：邻域取中位数 → 非线性，专治椒盐噪声，保边缘能力强
  • 高斯 vs 均值：高斯按距离衰减加权，模糊更"自然"；方差越大越模糊
均值一刀切、高斯看远近、中值挑中间；椒盐找中值，高斯噪声找高斯
Q
为什么中值滤波对椒盐噪声特别有效？🔥 高频

椒盐噪声是极端值（0 或 255 的孤立亮点/黑点）：

  • 均值/高斯滤波是线性加权，极端值会被"摊"进结果，噪声变成一片模糊灰雾
  • 中值滤波排序取中间值：极端大/小的噪声点排在两端，直接被丢弃
  • 且边缘处中值仍是两侧真实像素之一，所以保边能力强
排序一出，极端值出局；中值滤波，椒盐克星
Q
形态学操作有哪些？腐蚀和膨胀的区别？🔥 高频
操作 效果 典型用途
腐蚀 白色区域缩小 去小白点噪声、分离粘连物体
膨胀 白色区域扩大 填补小黑洞、连接断裂区域
开运算 先腐蚀再膨胀 去噪点、保持整体尺寸不变
闭运算 先膨胀再腐蚀 填小洞、连接裂缝

口诀化理解：腐蚀"瘦"、膨胀"胖"；开"去刺"、闭"填坑"。核的形状和大小决定操作粒度。

腐蚀瘦、膨胀胖，开去毛刺闭填坑
Q
SIFT 的原理和步骤？🔥 高频

SIFT = 尺度不变特征变换，具有尺度、旋转、光照不变性。四步：

  1. 尺度空间极值检测：高斯差分金字塔（DoG）找候选关键点
  2. 关键点定位：泰勒展开精化位置，剔除低对比度和边缘响应点
  3. 方向分配：统计邻域梯度直方图，主方向作为关键点方向（旋转不变）
  4. 特征描述：16×16 邻域分 4×4 子块，每块 8 方向直方图 → 128 维描述子
  • 匹配：两图描述子欧氏距离 + 最近邻/次近邻比值（Lowe's ratio < 0.75）筛选
  • 缺点：计算慢、专利问题；优点：极稳，遮挡/视角变化下仍能匹配
金字塔找点、精定位、定方向、128 维做描述
Q
SIFT、SURF、ORB 的对比？怎么选？🔥 高频
算法 关键点 描述子 速度 专利
SIFT DoG 金字塔 128 维浮点 慢 有专利
SURF Hessian + 积分图 64 维浮点 中 有专利
ORB FAST 角点 + 金字塔 BRIEF 二进制 快 免费开源

选择：实时性要求高（SLAM、移动端）用 ORB；匹配质量优先、算力充足用 SIFT。ORB 用汉明距离匹配（异或计数），比欧氏距离快得多。

要稳用 SIFT，要快要免费用 ORB，SURF 夹中间
Q
HOG 特征是怎么提取的？
  1. 预处理：灰度化 → Gamma 校正 → 计算梯度
  2. 分 cell（如 8×8 像素）：统计每个 cell 的梯度方向直方图（9 个方向 bin）
  3. 归一化：把 2×2 个 cell 组成 block，block 内做 L2 归一化（抗光照）
  4. 拼接所有 block 的直方图 → 得到最终特征向量

经典应用：HOG + SVM 行人检测（2005，Dalal & Triggs）。

梯度算方向，cell 做统计，block 管归一，拼接成特征
Q
RANSAC 的原理？🔥 高频

RANSAC = 随机抽样一致，从带噪声数据中拟合模型：

  1. 随机采样：随机挑最小数量点估计模型（如两点定直线、四点定单应矩阵）
  2. 计算内点：用模型测试所有点，误差小于阈值的为内点
  3. 重复迭代：保留内点最多的模型
  4. 用最佳模型的全部内点重新精化参数
  • 应用：特征匹配剔除外点、求解基础矩阵/单应矩阵、直线/圆拟合
  • 迭代次数公式：N = log(1-p) / log(1-w^s)（p 置信度、w 内点率、s 采样点数）
随机抽点拟模型，数一数谁是内点，内点最多者胜出

03 深度学习基础

Q
CNN 为什么适合处理图像？三大特性是什么？🔥 高频
  • 局部连接：每个神经元只连接输入的局部区域（图像局部相关性强），大幅减少参数
  • 权值共享：同一个卷积核在整张图上滑动（猫在左上角和右下角都用同一套参数检测），带来平移不变性
  • 层次化特征：浅层学边缘/纹理，中层学部件，深层学语义——自动特征提取，不用手工设计

对比全连接：224×224×3 输入若直接接 4096 神经元，参数约 3 亿；用 3×3 卷积仅几十个参数。

局部连接省参数，权值共享平移不变，逐层抽象出语义
Q
池化的作用？平均池化和最大池化怎么选？🔥 高频

池化作用：

  • 下采样降维：减小特征图、降低计算量
  • 扩大感受野：让后面的神经元"看"到更大范围
  • 平移鲁棒性：小位移不改变池化输出

两者区别：

  • 最大池化：保留最强响应，突出显著特征 → 分类网络主流
  • 平均池化：保留整体分布，信息更平滑 → 常用于网络末端（如 GoogLeNet 的全局平均池化代替全连接）
全局平均池化（GAP）可替代全连接层：无参数、抗过拟合、输入尺寸灵活。
池化三件事：降维、扩视野、抗位移；找特征用 max，保全局用 avg
Q
常见激活函数对比？各自的优缺点？🔥 高频
激活函数 公式/特点 优点 缺点
Sigmoid 压缩到 (0,1) 可解释为概率 梯度消失、非零中心、算 exp 慢
Tanh 压缩到 (-1,1) 零中心 仍梯度消失
ReLU max(0,x) 计算快、缓解梯度消失、稀疏激活 神经元死亡
Leaky ReLU 负区间小斜率 解决死亡问题 斜率需调参
GELU 概率加权平滑 平滑、Transformer 标配 计算略贵
Swish/SiLU x·sigmoid(x) 平滑、深层表现好 计算略贵

选择：CNN 默认 ReLU/Leaky ReLU；Transformer 用 GELU；二分类输出层用 Sigmoid，多分类输出层用 Softmax。

CNN 用 ReLU，Transformer 用 GELU，输出层看任务是 sig 还是 softmax
Q
ReLU 的"神经元死亡"是什么？怎么解决？
  • 原因：输入为负时梯度恒为 0，若某次大梯度更新使权重偏移过大，该神经元永远输出 0，"死了"
  • 解决：
    • 换 Leaky ReLU / PReLU（负区间给小斜率如 0.01）
    • 降低学习率、合适的权重初始化（He 初始化）
    • 用 GELU/Swish 等平滑替代
  • 为什么 ReLU 缓解梯度消失：正区间梯度恒为 1，链式相乘不衰减（对比 sigmoid 最大梯度 0.25）
负区梯度零就死，Leaky 给条活路；正区梯度一，深网不怕传
Q
BatchNorm 的原理和作用？训练和推理有什么区别？🔥 高频

原理：对每个 mini-batch 内的每个通道做标准化（减均值除方差），再通过可学习的 γ、β 缩放平移。

作用：

  • 缓解内部协变量偏移（ICS），允许更大学习率、加快收敛
  • 平滑损失面，有一定正则化效果
  • 降低对初始化的敏感度

训练 vs 推理（高频考点）：

  • 训练：用当前 batch 的均值方差，同时用滑动平均更新全局统计量
  • 推理：用累积的全局均值方差（running mean/var），不再依赖 batch
  • 因此训练时 batch 不能太小（否则统计量不准）；batch=1 的场景（超分、检测单图）慎用 BN，改用 GN/IN
训练用 batch 统计，推理用滑动平均；小 batch 换 GN，别跟 BN 死磕
Q
BN、LN、IN、GN 的区别？🔥 高频

四者公式相同（标准化 + 仿射），区别只在沿哪个维度统计均值方差（以 (N,C,H,W) 为例）：

方法 统计范围 典型场景
BN 每个通道，跨 N,H,W 大 batch 的分类/检测 CNN
LN 每个样本，跨 C,H,W RNN/Transformer（batch 无关）
IN 每个样本每个通道（跨 H,W） 风格迁移（去掉风格统计量）
GN 每个样本，通道分组 小 batch 目标检测/分割
BN 跨 batch，LN 跨通道，IN 单图单通道，GN 分组折中
Q
分类为什么用交叉熵而不是 MSE？🔥 高频
  • 梯度角度：sigmoid/softmax + MSE 的梯度包含 σ'(x) 项，错误大时梯度反而小 → 收敛慢；交叉熵配合 softmax 梯度简化为 ŷ - y，错得越多惩罚越大，收敛快
  • 概率角度：交叉熵衡量两个概率分布的差异，与分类输出的概率语义天然匹配
  • MSE 问题：分类标签离散，MSE 假设高斯噪声，用错了分布假设
  • MSE 适合回归任务（坐标、角度、深度），但角度回归要注意周期性（用 sin/cos 编码）
分类交叉熵、回归用 MSE；概率配交叉，欧氏配回归
Q
Focal Loss 是什么？解决了什么问题？
FL(p) = -(1 - p)^γ · log(p)

γ = 聚焦因子（常取 2），p 为预测正确概率
  • 背景：目标检测中前景/背景极度不平衡（1:1000），易分负样本的 loss 淹没难样本
  • 机制：(1-p)^γ 因子让易分样本（p 大）的 loss 权重趋近 0，聚焦难样本
  • 出自 RetinaNet（2017），让单阶段检测精度首次超过两阶段
易分样本打折，难分样本全价——样本不平衡就 Focal
Q
SGD 和 Adam 的区别？怎么选？🔥 高频
对比 SGD（+Momentum） Adam
机制 固定学习率 + 动量惯性 自适应学习率（一阶+二阶矩估计）
收敛 慢，需调学习率 快，对超参不敏感
泛化 最终精度往往更高 有时略差
适用 CV 大 batch 训练（检测/分割标配） Transformer、小数据快速实验
  • AdamW：Adam + 解耦权重衰减，Transformer 标配
  • 实践：CV 论文多用 SGD momentum=0.9；训练 ViT/检测头用 AdamW
要快用 Adam，要泛化 SGD 加动量；Transformer 一律 AdamW
Q
过拟合的表现和解决方案？🔥 高频

表现：训练损失持续下降，验证损失先降后升；训练精度远高于验证精度。

方案（按优先级）：

  • 加数据：数据增强（翻转/裁剪/MixUp/CutMix）、收集更多数据
  • 正则化：weight decay、Dropout
  • 降模型容量：换小 backbone、早停（early stopping）
  • 迁移学习：用预训练权重，冻结浅层
  • 集成/标签平滑：多模型平均、soft label
一加数据二正则，三减模型四早停
Q
梯度消失/爆炸的原因和解决方案？🔥 高频

原因：链式法则连乘——每层梯度 < 1 连乘趋零（消失），> 1 连乘爆炸（如 RNN 长序列、初始化不当）。

解决方案：

  • 结构：残差连接（ResNet）、LSTM 门控（RNN 场景）
  • 激活：ReLU 系替代 sigmoid
  • 归一化：BN/LN 稳定每层输入分布
  • 初始化：Xavier（tanh）/ He（ReLU）保持方差不变
  • 爆炸专用：梯度裁剪（clip by norm，RNN 必备）
连乘是根因；残差救深网，ReLU 保梯度，BN 稳分布，裁剪防爆炸
Q
Dropout 的原理？训练和推理有什么不同？
  • 训练：每个 batch 随机以概率 p 丢弃神经元（输出置 0），剩余按 1/(1-p) 放大（inverted dropout）
  • 推理：不丢弃，直接前向——因为训练时已放大，期望值一致，无需缩放
  • 作用：防止神经元"共适应"，相当于隐式训练指数级个共享参数的子网络（集成思想）
  • CV 中主要用于全连接层；卷积层常用 spatial dropout（丢弃整个通道）
训练随机丢、推理全保留；inverted 缩放在训练做，推理不用管
Q
为什么要做权重初始化？Xavier 和 He 的区别？
  • 全零初始化：所有神经元对称，学到相同特征 → 死网
  • 太大：梯度爆炸；太小：梯度消失
  • 目标：让每层输出方差 ≈ 输入方差，信号不放大不衰减
  • Xavier：配合 tanh/sigmoid，方差 = 1/fan_in（输入节点数）
  • He（Kaiming）：配合 ReLU（负半轴丢弃一半信息），方差 = 2/fan_in → CNN 默认
tanh 找 Xavier，ReLU 找 He；方差不放大，信号才稳当

Cosine 退火 余弦曲线降到接近 0 现代 CV 主流，平滑少调参

先热身、再冲刺、余弦缓落地
Q
1×1 卷积有什么作用？🔥 高频
  • 升维/降维：改变通道数（Network in Network 首创，Inception 大量使用），降维大幅省计算
  • 跨通道信息融合：在通道维度做全连接式组合
  • 增加非线性：后接 ReLU 即可，不改变空间尺寸
  • 例：256 通道 → 用 1×1 降到 64 → 再 3×3 卷积，计算量降到约 1/8（Bottleneck 结构）
1×1 三件事：变通道、融信息、加非线性；瓶颈结构省算力
Q
空洞卷积、转置卷积、深度可分离卷积分别是干什么的？🔥 高频
卷积变体 原理 用途

转置卷积 卷积的反向操作（插 0 再卷积） 上采样恢复分辨率（分割解码器）

  • 转置卷积有棋盘伪影 → 可用双线性上采样 + 3×3 卷积替代
空洞扩视野、转置做上采样、可分离省算力

Q
ResNet 为什么能训练上百层深的网络？🔥 高频

核心：残差学习，块内学习目标从 H(x) 改为残差 F(x) = H(x) - x，输出为 F(x) + x。

  • 问题背景：普通深网出现"退化"——更深网络训练误差反而更高（不是过拟合，是优化困难）
  • 梯度角度：恒等映射分支让梯度可以"无损直通"（加法对梯度恒为 1），深链梯度不消失
  • 优化角度：学残差比学恒等映射容易——"改一点点"比"从头学"简单；最差情况 F(x)=0，退化为恒等，深网不比浅网差
  • 细节：Bottleneck 结构（1×1 → 3×3 → 1×1）降维升维省计算；下采样放在捷径里用 1×1 卷积匹配维度
捷径一条路，梯度直接流；学的不是映射是残差，深网从此不怕退化
Q
Inception 模块的设计思想是什么？
  • 多尺度并行：同一输入并行经过 1×1、3×3、5×5 卷积和池化，再拼接——不知道该用多大卷积核就全用
  • 1×1 瓶颈降维（Inception v2/v3 改进）：先降通道再卷积，计算量大降
  • v3 改进：大核分解（5×5 → 两个 3×3、n×n → 1×n + n×1）、Label Smoothing、BN 辅助分类器
  • 本质：让网络自己学"要多大的感受野"，多尺度特征融合的早期典范
大小核一起上，1×1 先降维；不确定尺度就全试一遍
Q
MobileNet 为什么快？深度可分离卷积省了多少计算？🔥 高频

深度可分离卷积 = Depthwise（逐通道）+ Pointwise（1×1）

  • 普通卷积：DK·DK·M·N·DF·DF（核、输入通道 M、输出通道 N、特征图）
  • 可分离卷积：DK·DK·M·DF·DF + M·N·DF·DF
  • 计算量比值 = 1/N + 1/DK²，3×3 核、256 通道时约 1/8~1/9
  • 精度略降，但计算量降一个数量级 → 移动端标配
v2 加了倒残差（先升维再降维）+ 线性瓶颈；v3 用 NAS 搜索 + h-swish。答到 v1 原理 + 倒残差就是加分项。
逐通道扫一遍，1×1 融一遍，计算省到零头
Q
ViT 的核心思想？图像是怎么变成序列的？🔥 高频
  1. 切 patch：图像切成 16×16 的小块，展平成 token 序列（224/16 = 196 个 token）
  2. 线性嵌入：每个 patch 线性投影成 d 维向量（Patch Embedding）
  3. 加位置编码：可学习的 1D 位置 embedding，让模型知道 patch 位置
  4. 加 [CLS] token：汇聚全局信息的可学习 token
  5. 过标准 Transformer Encoder：多头自注意力 + MLP，堆 L 层
  6. [CLS] 输出接分类头
  • 关键结论：大数据集（JFT-300M）上超过 CNN；小数据不及 CNN（缺归纳偏置）→ DeiT 用蒸馏解决
切块成词、线性嵌入、加位置、CLS 打头、注意力通吃

CNN 和 ViT 的本质区别？各自优劣？🔥 高频

SENet 的通道注意力是怎么做的？
  1. Squeeze：全局平均池化把每个通道压成一个数（H×W → 1×1）
  2. Excitation：两级全连接（降维 → ReLU → 升维 → Sigmoid）学出每个通道的权重
  3. Reweight：权重逐通道乘回原特征

本质：让网络动态判断"哪个通道更重要"，即特征通道级的自适应校准。可插入任何 CNN，几乎零成本涨点。

Q
IoU 是什么？有什么变体？🔥 高频

IoU = 交集面积 / 并集面积，衡量预测框和真实框的重合度，取值 [0,1]。

  • 用途：NMS 去重、正负样本分配、mAP 评价、回归损失
  • GIoU：加最小包围框惩罚 → 两框不相交时仍有梯度
  • DIoU：加中心点距离惩罚 → 加快收敛
  • CIoU：再加长宽比一致性 → 三合一最优，YOLO 系列标配
交比并是 IoU；G 补不相交，D 拉中心， C 加宽高比
Q
NMS 的原理？Soft-NMS 解决了什么问题？🔥 高频

NMS（非极大值抑制）流程：

  1. 按置信度排序所有框
  2. 取最高分框保留，删掉与它 IoU 超过阈值（如 0.5）的其他框
  3. 对剩余框重复，直到处理完
  • Soft-NMS：不直接删除，而是对重叠框的分数乘以衰减函数（线性/高斯）→ 密集场景（相邻两人）下保住被误删的框
  • 其他变体：DIoU-NMS（考虑中心距）、Softer-NMS（框融合）
  • DETR 用集合匹配 + 匈牙利算法，天然不需要 NMS
分数最高的留，重叠超标的删；密集场景怕误杀，Soft 只降分不删框

Anchor 是什么？正负样本怎么分配？
  • Anchor：预设的一组不同尺度/长宽比的参考框（如 3 尺度 × 3 比例 = 9 个/位置），网络学的是相对 anchor 的偏移量，降低回归难度
  • 正样本：与某 GT 框 IoU 最大，或 IoU > 0.7 的 anchor
  • 负样本：与所有 GT 框 IoU < 0.3 → 背景类
  • 中间的忽略不参与训练 → 正负悬殊催生 Focal Loss
  • anchor-free（FCOS）：直接预测中心点到四边的距离 + centerness 分支，免去 anchor 超参
anchor 是模板，回归修偏移；正负看 IoU，中间不管它

FPN 特征金字塔解决了什么问题？🔥 高频

  • 效果：每层输出都"既有语义又有分辨率"，不同尺度目标在对应层检测 → 小目标精度大涨
  • 后续：PANet 加自底向上增强路径；BiFPN 双向 + 可学习权重

Q
mAP 是怎么计算的？AP 和 mAP 的关系？🔥 高频
  1. 所有预测按置信度从高到低排序
  2. 逐个判定 TP/FP（与某 GT 的 IoU ≥ 阈值且未匹配过 → TP）
  3. 累积计算不同置信度下的 精确率 P = TP/(TP+FP) 和 召回率 R = TP/所有 GT
  4. 画 PR 曲线，曲线下面积 = 该类的 AP
  5. 所有类别 AP 取平均 = mAP
  • mAP@0.5：IoU 阈值 0.5（VOC 风格）
  • mAP@0.5:0.95：IoU 从 0.5 到 0.95 步长 0.05 取平均（COCO 风格，更严格）
  • 新式算法（YOLOv8+）AP 用积分法（101 点插值）计算
排序、匹配、画 PR、算面积；单类是 AP，类均是 mAP
Q
边界框回归损失的演进？L1 → IoU → GIoU → DIoU → CIoU？🔥 高频
损失 形式 问题/改进
L1 / L2 逐坐标差 与 IoU 无关，同样误差 IoU 差异巨大；L1 在 0 点不可导 → Smooth L1
IoU Loss -ln(IoU) 尺度不变；不相交时 loss 相同且梯度为 0
GIoU IoU - 最小包围框占比 不相交时也有梯度
DIoU IoU - 中心距惩罚 直接拉近中心，收敛快
CIoU DIoU + 长宽比一致性 三因素齐全：重叠+中心+宽高比
L1 看坐标、IoU 看重叠、G 补距离、D 拉中心、C 比宽高
Q
小目标检测为什么难？有哪些优化手段？🔥 高频

难的原因：

  • 像素少 → 特征弱，多层下采样后信息几乎消失
  • 标注框小 → IoU 对偏移极敏感（1 像素偏移 IoU 大变）
  • 数据集中小目标样本占比低

优化手段：

  • 结构：FPN/PAN 多尺度融合、加浅层检测头（P2 层）、空洞卷积保分辨率
  • 数据：高分辨率输入/切片推理（SAHI 切图检测）、小目标过采样/复制粘贴增强
  • 标签分配：用 RFLA/NWD 等基于高斯分布的分配，缓解 IoU 敏感问题
  • 损失：归一化 Wasserstein 距离（NWD）替代 IoU 评价小框
下采样丢信息、IoU 太敏感；多尺度加浅层，切图升分辨率，复制粘贴做增广
Q
DETR 的核心思想？有什么优缺点？🔥 高频
  • 流程：CNN backbone 提特征 → 展平 + 位置编码 → Transformer Encoder（自注意力）→ Decoder 用 N 个可学习 object query 交叉注意力解码 → 每个 query 输出类别 + 框
  • 集合预测：预测 N 个框与 GT 做一对一匈牙利匹配，所以不需要 NMS 和 anchor
  • 优点：端到端、可扩展性强、全局关系建模
  • 缺点：训练极慢（500 epoch）、小目标差（分辨率细节在 encoder 前被下采样压缩）
  • 改进：Deformable DETR（稀疏采样收敛快 10 倍）、DINO、RT-DETR（实时）
query 问图要目标，匈牙利一对一配，无需 NMS 天然去重

06 图像分割

Q
语义分割、实例分割、全景分割的区别？🔥 高频
任务 含义 回答的问题 代表
语义分割 每个像素分类别 "这是路/车/人吗" FCN、U-Net、DeepLab
实例分割 类别 + 区分同类的个体 "这是第几辆车" Mask R-CNN、SOLO
全景分割 语义 + 实例统一 thing + stuff 全标注 Panoptic FPN、Mask2Former
  • thing：可数物体（人、车）；stuff：不可数背景（天空、道路）
语义只分类、实例分个体、全景全都要（thing + stuff）
Q
U-Net 的结构？为什么在医学图像上这么好用？🔥 高频
  • 结构：对称的编码器（下采样提语义）+ 解码器（上采样恢复分辨率）+ 跳跃连接（把编码器同尺度特征拼接到解码器）
  • 为什么好用：
    • 跳跃连接把浅层细节/边界信息直通到深层，弥补下采样丢失的空间信息
    • 参数少（~31M 以下），医学数据集小也能训练
    • 端到端输出像素级掩码，天然适合分割
  • 后续：3D U-Net、Attention U-Net、U-Net++（嵌套密集跳跃）、nnU-Net（自动调参医学神器）
下采样学语义，上采样复原，跳连保细节；数据少也能练，医学生的最爱
Q
上采样有哪些方法？
  • 插值：最近邻、双线性（无参数、稳定，分割最常用，常再接 3×3 卷积）
  • 转置卷积：可学习的上采样，但有棋盘伪影（核尺寸不能被步长整除导致不均匀重叠）
  • 反池化：max-unpooling 记录池化时的位置放回
  • 亚像素卷积（PixelShuffle）：通道重排到空间维（r²×C×H×W → C×rH×rW），超分常用
双线性最稳、转置可学有伪影、PixelShuffle 靠重排
Q
DeepLab 系列的核心？ASPP 是什么？
  • ASPP（空洞空间金字塔池化）：并行多个不同 rate 的空洞卷积 + 全局池化，拼接 → 多尺度上下文
  • v1：空洞卷积在不丢分辨率下扩大感受野
  • v2：ASPP 多尺度
  • v3+：加编码器-解码器结构，深层语义 + 浅层细节融合，backbone 换 Xception/深度可分离卷积
  • 输出比输入小 8 倍 → 最后双线性上采样回原尺寸（或 label 上采样）
空洞保分辨率，ASPP 看多尺度，v3+ 编码解码补细节
Q
分割为什么常用 Dice Loss？和 CE 怎么配合？
Dice = 2|A∩B| / (|A|+|B|)
Dice Loss = 1 - Dice
  • 优势：直接优化 IoD/Dice 指标本身；对小目标友好（像素少的类在 CE 中被淹没，Dice 是比例指标，天然平衡）
  • 缺点：小 batch 下梯度不稳（尤其单目标时），训练曲线震荡
  • 实践：BCE + Dice 各 0.5 加权最常见；大背景占优时再叠加 Focal 或 Online Hard Example Mining
Dice 管重叠、CE 管像素；两者各半，小目标有救
Q
RoIAlign 和 RoIPooling 的区别？🔥 高频
  • RoIPooling：候选框映射到特征图时坐标取整量化，两次量化误差在特征图上被放大，对检测影响小，对像素级掩码是灾难（边界错位 1 像素就是错）
  • RoIAlign：不取整，用浮点坐标 + 双线性插值采样每个 bin 内的值，再池化 → 像素级对齐
  • 这是 Mask R-CNN 相对 Faster R-CNN 的关键改动之一，让实例分割精度大涨
Pooling 两次取整误差大，Align 浮点插值贴边界
Q
分割的评价指标 mIoU 怎么算？🔥 高频 
单类 IoU = TP / (TP + FP + FN)
mIoU = 所有类别 IoU 的平均

混淆矩阵：行=预测，列=真实
TP: 预测对的正像素  FP: 误报  FN: 漏报
  • 其他指标：PA（像素准确率，受大类别主导）、Dice/F1、边界 IoU（对边缘敏感）
  • mIoU 是语义分割的"mAP"，比赛标准指标
交集除并集，各类求平均；分割看 mIoU，边界看 Boundary

07 度量学习与人脸识别

Q
人脸识别系统的完整流程？
  1. 人脸检测：MTCNN / RetinaFace 找到人脸框
  2. 关键点对齐：定位眼、鼻、嘴关键点，仿射变换把脸转正
  3. 特征提取：CNN backbone 提取 embedding（如 512 维向量），经 L2 归一化
  4. 比对：两向量余弦相似度，超过阈值判定同一人
  • 1:1 验证（刷脸支付）vs 1:N 识别（安防布控）——N 越大误识率越高，需要 ROC 曲线上选阈值
检测 → 对齐 → 提特征 → 算相似度；验证 1:1，识别 1:N
Q
Triplet Loss 的原理？怎么采样三元组？🔥 高频 
L = max(0, d(a, p) - d(a, n) + margin)

a: anchor 锚样本   p: positive 同类   n: negative 异类
目标：同类距离 + margin < 异类距离
  • 采样策略：随机采样的三元组大多"太容易"（loss=0 无梯度）→ 用难例挖掘：batch 内选最远的同类（hard positive）和最近的异类（hard negative）
  • 缺点：样本对爆炸、训练不稳定、margin 敏感
  • 演进：对比损失 → Triplet → Proxy 类代理 → 分类式度量学习（ArcFace 一条路走到黑）
锚点同类拉得近，异类推开 margin 远；难的样本才有用
Q
ArcFace 为什么效果好？加性角度间隔的核心思想？🔥 高频
  • 思路：把分类权重与特征的点积改写成 cos θ，在 logit 上加角度间隔 m：s·cos(θy+m) → 逼同类在角度空间更紧凑
  • 几何意义：每个类别在超球面上占据一个更"窄"的扇形区域 → 类内更聚、类间更开
  • 优势：训练稳定（对比 Triplet）、不需要复杂采样、embedding 判别力强
  • 同族：SphereFace（乘性间隔）、CosFace（加性余弦间隔）——ArcFace 是集大成者
  • 推理时丢弃分类头，只用 embedding 做比对
分类即度量：角上加个 m，同类抱成团；训练当分类，推理用向量

Q
类别不平衡怎么处理？🔥 高频
  • 数据层面：过采样小类（+增强）、欠采样大类、复制粘贴小类目标
  • 损失层面：类别加权 CE（weight 与频率成反比）、Focal Loss、Class-balanced Loss（按有效样本数）
  • 策略层面：两阶段解耦训练（先正常学表征，再重采样调分类头）、重加权延迟（前期不加权）

采样再平衡、损失做加权、训练分两段、评价看单类
Q
精确率和召回率的区别？F1 是什么？🔥 高频 
精确率 P = TP / (TP + FP)   → 查准：报出来的有多少是真的
召回率 R = TP / (TP + FN)   → 查全：真目标漏了多少
F1 = 2PR / (P + R)          → 调和平均，两者兼顾
  • P 高 R 低：宁可放过不可错杀（垃圾过滤）；R 高 P 低：宁可错杀不可放过（癌症筛查、安防布控）
  • PR 曲线：阈值越松 R 升 P 降，曲线下面积即 AP
P 管报得准，R 管抓得全；调和不偏科，场景定取舍
Q
迁移学习和微调怎么做？什么情况全量训练？🔥 高频
  • 流程：加载 ImageNet 预训练权重 → 替换最后分类层 → 小学习率先调头几层，再解冻全网络微调
  • 数据少 + 相似：只微调最后一层（linear probing）
  • 数据少 + 差异大：微调中后段，冻结浅层
  • 数据多：全量微调甚至从头训
  • backbone 用小学习率（如 1e-4），新层用大学习率（如 1e-3），差分学习率是标配技巧
  • 域差异大（红外 vs 可见光、医学影像）：浅层边缘特征仍通用，深层需大调
预训练打底，浅层通用深层专用；数据越多解冻越多，差分学习率开路
Q
训练 loss 不收敛/NaN，怎么排查？
  1. 数据：标注错乱、图片损坏、mean/std 错误、标签越界（如类别号 ≥ num_classes）
  2. 预处理：除零、归一化搞反、通道顺序错
  3. 学习率：过大是 NaN 首因 → 降 10 倍试；加 warmup
  4. 数值稳定：log(0)、除 0 → 加 eps；用 BCEWithLogitsLoss 替代 sigmoid+BCE
  5. 梯度：加 clip（如 max_norm=5）；检查梯度爆炸层
  6. 流程：先过拟合 1 个 batch 验证代码正确性——loss 应能降到接近 0
先小批过拟合验代码，再查数据和学习率；log 零除零加 eps，梯度大了就 clip
Q
什么是 TTA？什么是标签平滑？
  • TTA（测试时增强）：推理时对输入做多种变换（翻转、多尺度裁剪），分别预测后融合（平均/投票）→ 白拿 1~2 个点，代价是推理变慢
  • 标签平滑：把 one-hot 的 [0,1] 变成 [ε/K, 1-ε+ε/K] → 防止模型对预测过度自信，提升泛化（Inception v3、检测头常用）
TTA 多变体投票，标签平滑防自满

Q
模型压缩有哪些手段？🔥 高频
手段 原理 压缩/加速比
剪枝 去掉不重要的权重/通道/层（按幅值或重要性分数） 结构化剪枝 2~4 倍，精度损失小
量化 FP32 → INT8/INT4 表示权重和激活 INT8 约 4 倍提速、4 倍省内存
知识蒸馏 大模型（教师）监督小模型（学生）训练 学生小 10 倍，保住大部分精度

Q
量化的原理？PTQ 和 QAT 的区别？🔥 高频 
# 对称量化：真实值 = 量化值 × scale
scale = max|w| / 127          (INT8)
q = round(w / scale)
  • PTQ（训练后量化）：训完直接量化，用几百张校准图片统计激活分布 → 快，精度可能掉 1~2 个点
  • QAT（量化感知训练）：训练时插入伪量化节点模拟量化误差，让权重适应 → 精度几乎无损，但要重新训练
  • 为什么能加速：INT8 的乘加吞吐量是 FP32 的数倍（Tensor Core），且省带宽和内存
  • 坑点：异常大激活值会把 scale 撑大 → 其他值精度损失（可用 percentile/entropy 校准缓解）
PTQ 免训快掉点，QAT 慢工出细活；scale 一被撑大，精度全完蛋
Q
知识蒸馏的原理？软标签为什么有效？🔥 高频 
L = α · CE(y, student) + (1-α) · KL(soft_T, student_T)

soft_T = softmax(logits / T)   # T = 温度，通常 3~10
  • 软标签：教师输出的类别概率含"暗知识"——"这张猫图 90% 是猫，但更像狗而不像卡车"，比 one-hot 信息量大得多
  • 温度 T：放大 logits 差异让小概率类的相对关系显现
  • 蒸馏方式：logits 蒸馏（Hinton）、特征蒸馏（FitNet，中间层对齐）、关系蒸馏（样本间关系）
  • 应用：大模型→小模型压缩、自蒸馏（Born-Again）、半监督利用无标注数据
老师给软标签，温度一升暗知识显；logits 特征关系，三条路都可蒸
Q
常见的部署技术栈？ONNX / TensorRT / OpenVINO / NCNN 怎么选？🔥 高频
工具 厂商/平台 定位
ONNX Runtime 跨平台 通用推理引擎，模型交换格式（.onnx）事实标准
TensorRT NVIDIA GPU 极致优化：算子融合、FP16/INT8、kernel 自动调优
OpenVINO Intel CPU/iGPU 优化，Intel 平台首选
NCNN / MNN 腾讯/阿里 移动端 ARM 优化，无第三方依赖
Triton NVIDIA 服务化推理平台：动态 batch、多模型并发
  • 典型链路：PyTorch → export ONNX → parser 进 TensorRT → 生成 engine → 部署
  • 常见坑：自定义算子不支持（改写/注册 plugin）、动态 shape 处理、opset 版本兼容
N 卡找 TensorRT，Intel 找 OpenVINO，手机找 NCNN，中间都走 ONNX
Q
部署时精度对不上训练，怎么排查？（前后处理一致性）🔥 高频
  1. 预处理一致性（占 80% 的原因）：
    • resize 方式不同（双线性 vs 最近邻）
    • 通道顺序 BGR vs RGB
    • 归一化 mean/std 是否一致、除 255 顺序
    • letterbox 填充色/比例计算（检测常见坑）
  2. 数值精度：FP16/INT8 量化掉点 → 先验证 FP32 一致再量化
  3. 后处理：decode 框逻辑、置信度阈值、NMS 实现、anchor 顺序
  4. 验证方法：同一张图，PyTorch 和部署引擎各跑一遍，比对输入张量和输出 logits 误差（应 < 1e-4）
先对输入，再对输出，中间查精度；resize、通道、归一化，三大惯犯先提审

10 生成模型与多模态

Q
GAN 的基本原理？为什么生成器和判别器对抗？🔥 高频
  • 两个网络：
    • 生成器 G：噪声 z → 假图，目标是骗过 D
    • 判别器 D：输入图 → 真/假概率，目标是分辨真假
  • 博弈目标：minG maxD V(D,G)，理想终局是纳什均衡：G 生成的分布 = 真实分布，D 输出恒 0.5
  • JS 散度视角：GAN 在最小化生成分布与真实分布的 JS 散度
  • 经典变体：DCGAN（卷积 GAN）、cGAN（条件生成）、CycleGAN（风格迁移免配对）、StyleGAN（可控人脸生成）
G 造假骗 D，D 鉴假逼 G；越斗越像真的，均衡时真假难辨
Q
GAN 训练不稳定，有哪些稳定化技巧？
  • 损失改进：WGAN（Wasserstein 距离 + 权重裁剪/谱归一化）、LSGAN（最小二乘）、Hinge loss
  • 训练技巧：G/D 交替更新（如 D 更新 5 次再更新 G 1 次）、TTUR（两边不同学习率）、EMA 权重
  • 结构：谱归一化（SN）约束 D 的 Lipschitz、跳跃连接
  • 诊断：模式崩溃（mode collapse）——G 只会生成少数几种样本 → mini-batch discrimination、unroll
梯度不稳换 WGAN，模式崩溃查采样；谱归一化约束 D，交替训练别偏科
Q
扩散模型的原理？为什么能生成高质量图像？🔥 高频
  • 前向过程：对真实图逐步加高斯噪声，T 步后变成纯噪声（不可逆的破坏）
  • 反向过程：训练一个网络（U-Net/Transformer）学习"从噪声图预测每一步加的噪声"，推理时逐步去噪还原图像
  • 训练目标：简化为预测噪声的 MSE：L = E||ε - εθ(xt, t)||²
  • 为什么强：把生成建模成千百个小步去噪（相比 GAN 一步到位），每步任务简单、训练稳定、无对抗博弈，且渐进采样质量高

import numpy as np

def iou(box1, box2):
    """box: [x1, y1, x2, y2] 左上角/右下角格式"""
    # 1. 交集区域
    x1 = max(box1[0], box2[0])
    y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2])
    y2 = min(box1[3], box2[3])

    inter = max(0, x2 - x1) * max(0, y2 - y1)  # 无交集时为 0

    # 2. 并集 = 面积和 - 交集
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - inter

    return inter / (union + 1e-6)  # 防 0 除
左上取大、右下取小得交集；面积相加减交集得并集，交比并

def nms(boxes, scores, iou_thresh=0.5):
    """boxes: (N,4) [x1,y1,x2,y2]  scores: (N,)"""
    x1, y1, x2, y2 = boxes[:, 0], boxes[:, 1], boxes[:, 2], boxes[:, 3]
    areas = (x2 - x1) * (y2 - y1)

    order = scores.argsort()[::-1]   # 按分数从高到低排序
    keep = []

    while order.size > 0:
        i = order[0]                 # 当前最高分框
        keep.append(i)

        # 剩余框与当前框的 IoU（向量化）
        xx1 = np.maximum(x1[i], x1[order[1:]])
        yy1 = np.maximum(y1[i], y1[order[1:]])
        xx2 = np.minimum(x2[i], x2[order[1:]])
        yy2 = np.minimum(y2[i], y2[order[1:]])
        inter = np.maximum(0, xx2 - xx1) * np.maximum(0, yy2 - yy1)
        ious = inter / (areas[i] + areas[order[1:]] - inter + 1e-6)

        # 保留 IoU 小于阈值的框，删掉重叠度高的
        order = order[1:][ious < iou_thresh]

    return keep
排序取头，算重叠，删掉超标的；循环到空，留下的就是答案

def kmeans(data, k, iters=100):
    """data: (N, d)"""
    # 1. 随机初始化中心
    idx = np.random.choice(len(data), k, replace=False)
    centers = data[idx].copy()

    for _ in range(iters):
        # 2. 分配：每个点找最近的中心
        dist = np.linalg.norm(data[:, None] - centers[None], axis=2)
        labels = dist.argmin(axis=1)

        # 3. 更新：每类取均值作为新中心
        new_centers = np.array([
            data[labels == j].mean(axis=0) if np.any(labels == j) else centers[j]
            for j in range(k)
        ])
        if np.allclose(new_centers, centers):
            break
        centers = new_centers

    return labels, centers
先随机定心，再就近归队，队内取均值当新心；不动即收敛

# 3. 训练循环
for epoch in range(90):
    model.train()
    total, correct, loss_sum = 0, 0, 0.0
    for images, labels in loader:
        images, labels = images.cuda(), labels.cuda()

        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

        loss_sum += loss.item() * labels.size(0)
        correct  += (outputs.argmax(1) == labels).sum().item()
        total    += labels.size(0)
    scheduler.step()
    print(f"epoch {epoch}: loss={loss_sum/total:.4f} acc={correct/total:.4f}")
